# MSU2_MINI_V2
整合 https://github.com/dimangopie/just-fun-for-MSU2_MINI 和 https://github.com/dchg43/msu2_mini 的程序。

因为新买的“USB小屏幕0.96寸USB直插式电脑监控小屏”，没有源码，只有exe程序。

https://github.com/dimangopie/just-fun-for-MSU2_MINI 花屏，但是修改一下，也能正常显示，但是退出的时候就一直调频率，退不出来。

https://github.com/dchg43/msu2_mini 能连接，有显示，就是感觉缺点啥。

所以也懒得搞为什么，直接整合一起，再优化，增加一些功能。

等测试好再上传源码。

## 1. 引言

### 1.1 这是什么？

**USB 副屏工具 (MSU2_MINI_V2)** 是一款专门为 USB 小屏幕设计的桌面软件。它可以将你的电脑信息实时显示在一个小小的外接屏幕上——就像一个放在桌面的智能仪表盘。

### 1.2 它能做什么？

| 应用场景 | 你能看到什么 |
|---------|------------|
| 🖥️ **电脑监控** | CPU/内存/磁盘/网络使用率、温度、风扇转速 |
| ⏰ **桌面时钟** | 大字时钟、世界时钟、农历日期 |
| 📊 **数据仪表盘** | 自定义仪表盘显示你关心的任何数据 |
| 📰 **信息订阅** | 天气、加密货币行情、微博热搜 |
| 🎨 **创意展示** | 跑马灯文字、GIF动图、相册轮播 |
| 🔧 **开发者工具** | API投屏、程序窗口镜像、自定义脚本 |

### 1.3 适合谁用？

| 用户类型 | 使用场景 |
|---------|---------|
| 🏠 **普通用户** | 桌面时钟、天气显示、电脑状态监控 |
| 🎮 **游戏玩家** | 游戏时监控CPU/GPU温度、网络延迟 |
| 💼 **办公人员** | 显示待办事项、纪念日、番茄钟 |
| 👨‍💻 **开发者** | API投屏调试、自定义内容显示 |
| 🎨 **创作者** | 展示作品、动图相册、跑马灯 |
| 📈 **交易员** | 实时加密货币行情、网络延迟监控 |

## 2. 快速开始

### 2.1 下载与安装

1. 从 GitHub Releases 下载最新版本
2. 解压到任意文件夹（建议英文路径）
3. 以**管理员身份**运行 `MSU2_MINI_V2.exe`

> 💡 **为什么需要管理员权限？**  
> 管理员权限可以读取CPU温度、风扇转速等硬件传感器数据。

### 2.2 连接硬件

1. 将USB小屏幕插入电脑的USB接口
2. 软件会自动检测并连接设备
3. 看到状态变为「设备已连接」即可开始使用

### 2.3 选择显示内容

1. 点击「主控」标签页
2. 在「页面下拉列表」中选择要显示的内容
3. 小屏幕会立即切换显示

### 2.4 常用页面推荐

```
新手推荐顺序：
1. 📱 屏幕镜像 → 看电脑屏幕在小屏上的效果
2. 🕐 时间 → 大字时钟，最实用的功能
3. 📊 电脑监控 → 查看电脑运行状态
4. 🌤️ 天气 → 桌面天气站
```

## 3. 硬件准备

### 3.1 支持的设备

本软件支持以下类型的USB小屏幕：

| 设备类型 | 常见尺寸 | 说明 |
|---------|---------|------|
| MSU2_MINI 系列 | 160×80, 128×64, 240×240 | 主推设备 |
| WCH 芯片方案 | 多种尺寸 | VID=0x1A86 |
| USB串口屏 | 任意尺寸 | 需支持MSN协议 |

### 3.2 硬件连接图示

```
[USB小屏幕] 
    ↓ (USB数据线)
[电脑USB接口]
    ↓
[软件自动识别]
    ↓
[显示内容]
```

### 3.3 屏幕分辨率设置

软件会自动检测屏幕分辨率，也支持手动设置：

1. 在主控页找到「屏幕分辨率」下拉菜单
2. 选择对应的分辨率：
   - `160×80 (默认)` - 最常见
   - `128×64` - 0.96寸OLED
   - `240×240` - 1.54寸圆形屏
   - `320×240` - 2.4寸屏
   - `240×320` - 竖屏模式
3. 点击「检测屏幕」可自动识别

### 3.4 多设备支持

软件支持同时连接多个USB副屏，每个屏幕独立工作：

- 每个屏幕有独立的配置文件
- 按USB序列号(SN)自动识别
- 可独立设置页面、方向、颜色
- 在「已连接设备」下拉栏切换控制

### 5.2 页面切换方式

1. **下拉选择**：从下拉列表直接选择
2. **键盘按键**：
   - 单击小屏按键 = 下翻页
   - 双击小屏按键 = 上翻页
   - 长按小屏按键 = 切换显示方向
3. **自动翻页**：在设置中开启自动轮播
4. **API控制**：通过HTTP API切换

### 5.3 各页面详解

#### 🕐 时间页面 (PCTIME_PAGE_ID)

**功能**：大字体显示当前时间（HH:MM）

**配置方式**：
- 「文字颜色」滑块调整时间颜色
- 需先烧写背景图像（参见烧写部分）

**显示效果**：
```
    ┌──────────────┐
    │  12:34        │  ← 大号数字，居中显示
    │               │
    └──────────────┘
```

#### 📊 系统监控 (STATE_PAGE_ID)

**功能**：显示CPU/内存/磁盘/电池使用率

**配置方式**：
- 「文字颜色」调整数字颜色
- 背景固定为烧写的背景图

**显示效果**：
```
    ┌──────────────┐
    │ CPU  45%     │
    │ MEM  67%     │
    │ BAT  82%     │
    │ DSK  34%     │
    └──────────────┘
```

#### 🌐 网络流量 (NETSPEED_PAGE_ID)

**功能**：实时网络上传/下载速度曲线图

**配置方式**：
- 设置 → 监控显示 → 网络流量
- 选择「经典」或「自定义」模式
- 自定义模式下可分别设置上传/下载文字颜色和柱状图颜色

**显示效果**：
```
    ┌──────────────┐
    │ 上传 125KB/s  │
    │ ████░░░░░░   │
    │ 下载 3.2MB/s  │
    │ ████████░░   │
    └──────────────┘
```

#### 🖥️ 屏幕镜像 (SCREEN_PAGE_ID)

**功能**：将电脑窗口或桌面显示在小屏幕上

**操作步骤**：
1. 在「屏幕镜像窗口」下拉列表选择要镜像的程序
2. 支持选择：
   - 桌面（整个屏幕）
   - 任意窗口（浏览器、游戏、软件）
   - 多显示器（每个显示器独立选项）

**高级功能**：
- **填充/适应**：选择图像如何适配小屏
- **放大镜模式**：跟随鼠标放大局部区域
- **FPS控制**：调整刷新率（1-50）

#### 📷 相机视频 (CAMERA_VIDEO_ID)

**功能**：显示电脑摄像头画面

**操作步骤**：
1. 在「相机名称」下拉列表选择摄像头
2. 软件自动显示摄像头画面
3. 调整FPS控制流畅度

> ⚠️ **注意**：部分摄像头需要先打开相机软件才能被识别

#### 📈 自定义显示 (CUSTOM1/CUSTOM2)

**简单模式（CUSTOM1）**：
- 显示两行数据+实时柱状图
- 可从LibreHardwareMonitor选择传感器
- 适合显示CPU/GPU/温度等

**高级模式（CUSTOM2）**：
- 完全自定义模板
- 支持文字、图片、数值、图形
- 可视化编辑器（图形化编辑）

## 6. 高级功能

### 6.1 烧写功能

烧写是将图片、动图等数据写入小屏幕Flash存储的过程。

#### 烧写内容类型

| 类型 | 用途 | 文件格式 |
|-----|------|---------|
| 闪存固件 | 设备固件升级 | .bin |
| 背景图像 | 时间页面的背景 | 图片格式 |
| 相册图像 | 相册页面的图片 | 图片格式 |
| 动图文件 | 动图播放 | .gif 或 36张序列图 |

#### 动图烧写详解

**方式一：GIF文件**
1. 选择GIF文件
2. 软件自动解析每帧
3. 自动计算建议播放间隔
4. 点击烧写

**方式二：36张序列图**
1. 准备36张图片（命名为 A0.jpg, A1.jpg ... A35.jpg）
2. 选择第一张图片（A0.jpg）
3. 软件自动查找并转换所有图片
4. 点击烧写

### 6.2 自定义显示内容编辑器

完全自定义是小屏最强大的功能之一。

#### 基本命令

| 命令 | 语法 | 示例 | 说明 |
|-----|------|------|------|
| `p` | `p 文本` | `p Hello` | 显示文本 |
| `a` | `a 锚点` | `a la` | 设置文本锚点 |
| `m` | `m x y` | `m 10 20` | 移动到绝对坐标 |
| `t` | `t dx dy` | `t 8 0` | 相对移动 |
| `f` | `f 字体 字号` | `f simhei.ttf 20` | 设置字体 |
| `c` | `c 颜色` | `c #ff0000` | 设置颜色 |
| `i` | `i 图片路径` | `i logo.png` | 插入图片 |
| `v` | `v 序号 格式` | `v 1 {:.1f}` | 显示传感器数值 |
| `r` | `r x1 y1 x2 y2` | `r 10 10 50 50` | 绘制矩形 |
| `l` | `l x1 y1 x2 y2` | `l 0 0 159 79` | 绘制线条 |
| `o` | `o x y 半径` | `o 80 40 20` | 绘制圆形 |
| `g` | `g GIF路径` | `g anim.gif` | 显示动图 |

#### 模板示例：科技感监控面板

```
# 背景图片
i resource/example_background.png

# 设置颜色和字体
c #ff3333
f resource/Orbitron-Regular.ttf 22

# CPU
m 16 16
v 1 {:.0f}
p %

# GPU
m 96 16
v 2 {:.0f}
p %

# 内存
m 96 44
v 3 {:.0f}
p %
```

#### 图形化编辑器

对于不熟悉命令的用户，软件提供了图形化编辑器：

1. 点击「自定义内容」
2. 切换到「图形化编辑」标签页
3. 使用按钮添加元素
4. 双击列表项编辑
5. 实时预览效果

### 6.3 自定义传感器选择

LibreHardwareMonitor 支持读取多种硬件传感器：

#### 传感器类型

| 类型 | 说明 | 示例 |
|-----|------|------|
| Temperature | 温度 | CPU温度、GPU温度、主板温度 |
| Fan | 风扇转速 | CPU风扇、机箱风扇 |
| Voltage | 电压 | CPU核心电压、内存电压 |
| Load | 负载 | CPU占用、GPU占用 |
| Power | 功耗 | CPU功耗、GPU功耗 |
| Clock | 频率 | CPU频率、内存频率 |
| Throughput | 吞吐量 | 网络速度、磁盘速度 |

#### 选择传感器

1. 点击「自定义内容」
2. 在「显示多项数值」或「显示两项图表」标签页
3. 从下拉列表选择传感器
4. 可自定义显示名称

### 6.4 跑马灯配置

**功能**：文字水平滚动显示

**配置位置**：设置 → 页面内容 → 文字跑马灯

**可调参数**：
- 文本内容
- 字号（8-72）

## 7. API 投屏

### 7.1 什么是API投屏？

API投屏允许其他程序通过HTTP请求或WebSocket连接来控制小屏幕显示内容。

**适用场景**：
- 🧪 **开发调试**：在开发过程中实时显示调试信息
- 📊 **数据可视化**：自定义数据展示面板
- 🎮 **游戏辅助**：显示游戏内数据
- 🤖 **自动化**：脚本控制屏幕内容

### 7.2 启用API服务

1. 打开「设置」→「API接入」
2. 勾选「启用 API 投屏服务器」
3. 设置端口（默认8632）
4. 可选：设置访问令牌

### 7.3 基础API使用

#### 查看设备信息
```bash
curl http://127.0.0.1:8632/api/info
```

#### 投屏文本
```bash
curl -X POST http://127.0.0.1:8632/api/text \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello World"}'
```

#### 投屏图像
```bash
# 图像需要base64编码
curl -X POST http://127.0.0.1:8632/api/screen \
  -H "Content-Type: application/json" \
  -d '{"image":"iVBORw0KGgo..."}'
```

#### 切换页面
```bash
curl -X POST http://127.0.0.1:8632/api/page \
  -H "Content-Type: application/json" \
  -d '{"page":"时间"}'
```

#### 清屏
```bash
curl -X POST http://127.0.0.1:8632/api/clear
```

### 7.4 原始字节流投屏（最高性能）

```bash
# 发送RGB888原始数据（W*H*3字节）
curl -X POST http://127.0.0.1:8632/api/screen/raw \
  -H "Content-Type: application/octet-stream" \
  --data-binary @frame.rgb
```

### 7.5 WebSocket实时通道

```javascript
// JavaScript 示例
const ws = new WebSocket('ws://127.0.0.1:8632/ws');

// 发送文本
ws.send(JSON.stringify({type:'text', text:'Hello WebSocket'}));

// 发送图像（二进制RGB888）
const data = new Uint8Array([...]); // W*H*3 字节
ws.send(data);
```

### 7.6 Python集成示例

```python
import requests
import base64

# 投屏文本
requests.post("http://127.0.0.1:8632/api/text", json={"text": "系统运行中"})

# 投屏图像
with open("screenshot.png", "rb") as f:
    b64 = base64.b64encode(f.read()).decode()
    requests.post("http://127.0.0.1:8632/api/screen", json={"image": b64})

# 切换页面
requests.post("http://127.0.0.1:8632/api/page", json={"page": "时间"})
```

### 7.7 多屏投屏

API支持指定目标屏设备：

```python
# 投屏到屏幕2
requests.post("http://127.0.0.1:8632/api/text", json={
    "text": "屏幕2测试",
    "device": "屏幕2"
})

# 查看设备列表
requests.get("http://127.0.0.1:8632/api/devices").json()
```

### 7.8 多图轮播API

```python
import requests
import base64

images = []
for img in ["pic1.png", "pic2.png", "pic3.png"]:
    with open(img, "rb") as f:
        images.append(base64.b64encode(f.read()).decode())

requests.post("http://127.0.0.1:8632/api/slideshow", json={
    "images": images,
    "interval": 3.0,
    "fit": "cover"
})
```

## 9. 故障排除

### 9.1 常见问题与解决方案

#### ❌ 设备未连接

| 原因 | 解决方案 |
|-----|---------|
| USB线未连接 | 检查USB线是否插好 |
| 驱动未安装 | 安装CH340/CP2102驱动 |
| 端口被占用 | 关闭其他串口软件 |
| 设备故障 | 尝试更换USB口或重启设备 |

#### ❌ 画面倾斜/花屏

| 原因 | 解决方案 |
|-----|---------|
| 分辨率不匹配 | 手动设置正确分辨率 |
| 方向设置错误 | 切换显示方向 |
| 通信干扰 | 检查USB线质量 |
| 软件版本不匹配 | 更新到最新版本 |

#### ❌ CPU温度/传感器不显示

| 原因 | 解决方案 |
|-----|---------|
| 未以管理员运行 | 右键→以管理员身份运行 |
| 传感器不支持 | 部分老硬件不支持 |
| LibreHardwareMonitor未加载 | 等待加载完成 |

#### ❌ 烧写失败

| 原因 | 解决方案 |
|-----|---------|
| 文件格式不支持 | 使用支持的格式 |
| 设备断开 | 检查连接 |
| 空间不足 | 检查Flash剩余空间 |

### 9.2 崩溃日志

程序崩溃时会在程序目录生成 `crash_log.txt` 文件，可用于排查问题。

### 9.3 日志级别

| 级别 | 说明 | 显示位置 |
|-----|------|---------|
| 信息 | 正常操作记录 | 信息输出框 |
| 警告 | 非致命问题 | 信息输出框 + 控制台 |
| 错误 | 需要关注的问题 | 信息输出框 + 控制台 |
| 调试 | 详细调试信息 | 控制台（开发者） |

### 9.4 性能优化

| 问题 | 优化方案 |
|-----|---------|
| CPU占用高 | 降低FPS值 |
| 画面卡顿 | 降低FPS或关闭实时预览 |
| 内存占用高 | 减少自定义模板复杂度 |
| 网络延迟高 | 使用更快的网络或本地数据 |

## 11. 常见问题 (FAQ)

### Q1: 软件提示需要管理员权限，但我不是管理员怎么办？

A: 非管理员模式也能使用大部分功能，但CPU温度、风扇转速等硬件传感器数据将无法读取。建议联系管理员获取权限，或使用不需要硬件传感器的页面（如时钟、相册、跑马灯）。

### Q2: 我的屏幕显示方向不对怎么办？

A: 在主控页面的「方向」下拉列表中选择正确的方向，或长按小屏按键循环切换。

### Q3: 如何让屏幕在没人操作时自动息屏？

A: 在「设置」→「自动化」中设置「无操作息屏超时」，单位秒。设置后，超过设定时间无按键操作会自动息屏，按小屏按键唤醒。

### Q4: 屏幕镜像黑屏怎么办？

A: 请尝试以下步骤：
1. 确认窗口未最小化
2. 尝试选择桌面或其他窗口
3. 在「屏幕镜像窗口」下拉列表重新选择
4. 某些游戏或全屏应用可能无法镜像

### Q5: 如何让软件开机自动启动？

A: 在「设置」→「通用」中勾选「开机自启动」。

### Q6: 配置可以导出备份吗？

A: 可以。在「设置」→「数据管理」点击「导出配置」保存为JSON文件，需要时「导入配置」恢复。

### Q7: 多个屏幕如何分别控制？

A: 在主界面顶部的「已连接设备」下拉栏选择要控制的屏幕，每个屏幕的页面、方向、颜色等设置独立保存。

### Q8: 自定义模板中的数值序号对应什么？

A: 在「自定义内容」→「显示多项数值」标签页中，第1-6行的项目分别对应 `v 1` 到 `v 6`。

### Q9: 天气显示城市支持中文吗？

A: 支持，直接输入中文城市名如「北京」即可。

### Q10: 为什么热搜显示“获取失败”？

A: 可能是网络问题，请检查网络连接。微博接口偶尔会变更，如有问题请提交GitHub Issue。

### Q11: 音乐页面显示“需安装winsdk库”？

A: 运行以下命令安装：`pip install winsdk`

### Q12: 软件会收集个人数据吗？

A: 不会。所有数据仅在本地处理，不联网上传任何个人数据。
