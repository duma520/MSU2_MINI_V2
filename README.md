所以也懒得搞为什么，直接整合一起，再优化，增加一些功能。

## 第一部分：快速上手指南（人人可懂的入门教程）

本章节的目标是让您在30分钟内，将一块空白的小屏幕变成有用的信息中心。

### 1. 什么是“USB副屏工具”？

简单来说，这是一款运行在Windows电脑上的免费软件。它通过USB数据线，将一块小屏幕（通常被称为“副屏”或“迷你显示器”）连接到您的电脑。然后，您可以用这款软件，在小屏幕上“投屏”或“显示”各种信息。

它和普通显示器的区别在于：
-   **尺寸小巧：** 通常只有1.3英寸到2.4英寸，可以放在桌面上，不占空间。
-   **信息聚焦：** 它不是用来替代主显示器的，而是专门用来“盯”某一类关键信息，让您不用切换窗口就能看到。
-   **高度定制：** 您可以通过一个叫做“自定义显示”的功能，像搭积木一样，拼凑出完全属于自己的显示界面。

### 2. 我需要准备什么？（硬件和软件）

-   **硬件：**
    1.  **一块USB小屏幕：** 一般是MSU2_MINI或基于相同芯片方案的设备。它看起来像一个小号的手机屏幕，带有一个USB接口。
    2.  **一台Windows电脑：** 本软件支持Windows 7/10/11。
    3.  **一根USB数据线：** 用于连接屏幕和电脑。
-   **软件：**
    1.  **主程序：** 您需要从GitHub的发布页面下载 `MSU2_MINI_V2.exe`。
    2.  **驱动：** 部分小屏幕可能需要安装CH340或CP2102等USB转串口驱动。软件会自动尝试连接，如果连接失败，请在网上搜索“CH340驱动”并安装。

### 3. 三步完成首次运行

1.  **连接硬件：** 使用USB数据线，将小屏幕连接到电脑的USB接口。电脑可能会发出“叮咚”的连接声。
2.  **启动软件：** 双击运行 `MSU2_MINI_V2.exe`。如果系统提示安全风险，请选择“仍要运行”。
3.  **自动连接：** 如果驱动正常，您会看到软件主界面顶部显示“设备已连接”。如果没有，请点击“刷新”按钮，或稍等片刻，软件会自动尝试连接。

**恭喜您！** 现在您的小屏幕应该已经亮起，并显示“屏幕镜像”画面——也就是您电脑屏幕的实时画面。至此，最基础的连接已经完成！

### 4. 我的第一个“非镜像”页面：显示时间

镜像功能很酷，但我们的目标是显示更丰富的信息。让我们把它切换到“时间”页面。

-   在软件主界面的“中控”标签页里，找到“页面：”旁边的下拉菜单，点击它，然后选择“时间”。
-   您会发现，小屏幕立刻变黑，并显示出了一个大大的、漂亮的数字时钟！这就是“时间”页面。

这就是软件最基本的使用方式：通过下拉菜单或点击“▲上翻”/“▼下翻”按钮，在不同的信息页面之间切换。

## 第二部分：功能百科全书（从新手到专家的功能全览）

本章节将系统性地介绍软件的全部功能，并附有大量生活和工作中的使用场景举例。

### 第一章：核心概念与界面导航

#### 1.1 核心概念：多屏与配置
您可能会在软件里看到“屏幕1”、“屏幕2”这样的标签。这意味着软件**支持同时连接和管理多块小屏幕**！
每块屏幕都是独立的。您在“屏幕1”上设置显示天气，在“屏幕2”上设置显示系统监控，它们互不干扰。软件会为每块屏幕（根据其USB序列号）自动保存独立的配置文件。重新插拔后，您的设置依然存在。

#### 1.2 主界面结构
软件界面主要分为三层：
1.  **顶部栏：** 显示已连接设备列表，并提供“刷新”按钮。
2.  **主标签页：** 包含“中控”、“电视墙”、“关于”。
    -   **中控：** 这是主要工作区，用于管理所有副屏。
    -   **电视墙：** 当您连接多块屏幕时，这里可以像监控室一样，同时看到所有屏幕的画面。
    -   **关于：** 显示软件版本、作者和许可证信息。
3.  **设备标签页（在“中控”内）：** 每一块连接的屏幕都有一个自己的标签页（如“屏幕1”）。点击它，即可对该屏幕进行独立设置。
4.  **屏幕内部子标签页（在“屏幕1”内）：** 包含“主控”、“设置”、“设备信息”。
    -   **主控：** 快速控制区，用于切换页面、调整颜色、烧写固件等。
    -   **设置：** 深度定制区，所有详细配置都在这里。
    -   **设备信息：** 查看该屏幕的硬件和连接详情。

“主控”子标签页是您最常打交道的面板，所有高频操作都集中在这里。

| :--- | :--- | :--- | :--- |

### 第三章：设置中心完全攻略（深度定制）

“设置”子标签页是软件的大脑，所有强大的定制功能都隐藏在这里。我们按标签页一一介绍。

#### 3.1 通用 (General)

-   **防烧屏：** 针对OLED屏幕，每隔30秒将画面整体移动1-2个像素，防止静态画面在屏幕上留下残影。**建议保持开启。**
-   **开启实时预览：** 与主控台的开关联动。
-   **显示信息框：** 决定是否显示软件底部的消息日志区域。如果您希望界面更清爽，可以关闭它。
-   **能效模式（★★★★★）：**
    -   **这是什么？** 软件运行需要占用CPU资源。如果您希望电脑省电或减少发热（尤其是在笔记本电脑上），可以启用此功能。
    -   **如何选择？**
        -   **均衡（默认）：** 性能与功耗平衡，适合日常使用。
        -   **1级/2级能效：** 适合长期挂机（比如只显示静态时间或信息），能显著降低CPU占用率。1级是“最省电”模式。
        -   **3-5级能效：** 降低幅度逐级减小，适合在需要较高刷新率（如显示动态数据）但又想省电时使用。
    -   **底层原理（专业向）：** 此模式会动态调整所有后台任务（截图、渲染、网络请求、按键检测）的**等待间隔**和**刷新频率**。例如，在1级能效下，CPU采样和屏幕刷新率都会成倍降低。
-   **开机自启动：** 让软件随Windows系统自动启动，实现“无感”开机运行。
-   **界面语言：** 支持中文和English切换。

#### 3.2 自动化
-   **自动翻页轮播：** 让您的小屏幕像幻灯片一样，在您设置的多个页面之间自动循环切换。非常适合在店铺或展会上展示多种信息。
-   **无操作息屏超时：** 设定一个时间（秒）。如果在这个时间内没有任何按键操作，小屏幕将自动熄灭。按下按键即可唤醒。这是保护OLED屏幕和节省电力的好方法。

#### 3.3 按键
此功能用于自定义小屏幕上唯一的那个物理按键（或触摸按键）的行为。
-   **单击/双击/长按：** 您可以分别为这三种操作分配不同的功能。
-   **可分配的动作：** “下翻页”、“上翻页”、“切换方向”、“无”。
-   **使用举例：** 将“单击”设为“下翻页”，将“长按”设为“切换方向”。这样您就可以不依赖鼠标，完全用物理按键来切换信息和旋转屏幕了。

#### 3.4 页面内容

这里集中管理每个“静态”或“半动态”页面的具体内容。

-   **文字跑马灯：**
    -   **场景：** 在办公桌上显示“正在开会，请勿打扰”，或者在公司前台显示欢迎语。
    -   **功能：** 设置文本、字号、滚动速度和颜色。文字会像广告牌一样从右向左滚动。
-   **天气与行情：**
    -   **场景：** 交易员或投资者用来实时盯盘。
    -   **功能：** 输入城市名（支持中文，如“北京”）获取天气；输入交易对（如 `BTCUSDT,ETHUSDT`）获取加密货币实时价格。
-   **热搜：**
    -   **场景：** 自媒体人或吃瓜群众，随时了解微博热点。
    -   **功能：** 自动抓取微博热搜榜。您可以设置显示条数、是否自动滚动、翻页间隔等。
-   **时间：**
    -   **番茄钟：** 为工作或学习设定一个倒计时（如25分钟），培养专注习惯。
    -   **世界时钟：** 输入格式如 `北京|8,纽约|-5`，可以同时查看多个时区的时间，非常适合跨国团队协作。
-   **纪念日与待办：**
    -   **纪念日：** 输入格式 `名称|月-日`，如 `恋爱纪念日|05-20`，屏幕会显示“恋爱纪念日 还有 30 天”。
    -   **待办事项：** 输入您的任务清单，可以在小屏幕上随时查看。

#### 3.5 监控显示

这是整个软件最强大的数据监控中心。

-   **进程：** 显示当前占用内存最高的几个进程，方便您快速找出“吃内存”的软件。
-   **硬件详情：** 需要以**管理员身份**运行软件才能获取全部数据。
    -   **监控类型：** 您可以勾选想看的数据类型，如温度(Temperature)、风扇转速(Fan)、电压(Voltage)、负载(Load)、功耗(Power)。
    -   **传感器选择：** 这是**专家级功能**。您可以通过点击“...”按钮，在弹出的对话框中**精确选择**来自哪个硬件（如CPU核心1、GPU显存）的哪个传感器。这给了您无与伦比的监控自由度。
-   **仪表盘：**
    -   **场景：** 游戏玩家或硬件发烧友，以图形化的“仪表盘”方式实时监控系统状态。
    -   **功能：** 您可以选择显示CPU/内存/磁盘占用率、CPU/GPU温度、风扇转速、网络上传/下载速率。每一项都可以**独立设置颜色**，让界面更直观。
-   **磁盘读写：**
    -   **场景：** 当您在进行大文件复制或视频渲染时，监控硬盘的读写速度。
    -   **三种模式：**
        1.  **经典：** 清晰的文字列表。
        2.  **经典2：** 布局类似网络流量，带有柱状图。
        3.  **网速样式：** 完全仿照网络流量监控的样式。
-   **网络流量：**
    -   **场景：** 监控电脑的上传/下载网速。
    -   **功能：** 支持“经典”和“自定义”两种模式。在“自定义”模式下，您可以为上传/下载的文字和柱状图设置不同的颜色。

#### 3.6 屏幕镜像
-   **镜像局部放大（跟随鼠标）：**
    -   **场景：** 设计或绘图时，需要精确观察某个像素区域。
    -   **功能：** 开启后，副屏会显示您鼠标周围区域的一个放大视图，就像给电脑屏幕装了一个“放大镜”。

#### 3.7 配色方案

这是一个非常人性化的设计，让您不必一个一个地调颜色。
1.  **内置方案：** 软件内置了260多种配色方案，从“马卡龙”、“赛博朋克”到“中国传统色”，应有尽有。
2.  **混合搭配：** 您可以先选择“赛博朋克”方案，软件会在每个颜色设置项旁显示该方案的色板。然后您可以从“莫兰迪”方案的色板中取一个颜色，用到“网络流量”的上传速度上，实现“混搭”风格。
3.  **存为新方案：** 调好一套满意的颜色后，点击“存为新方案”，它就会保存在您的配置中，可以随时调用。

#### 3.8 API接入

这是面向开发者和极客用户的强大功能。简单来说，它让**任何能发送网络请求的程序**，都可以控制小屏幕显示什么。

-   **启用 API 投屏服务器：** 打开此开关，软件就会在后台启动一个本地服务器。
-   **工作原理：** 外部程序（比如您自己写的一个Python脚本、一个网页，甚至是一个手机App）可以向这个服务器发送特定的指令（我们称之为“API命令”），来告诉小屏幕“显示这张图片”、“显示这段文字”或“切换页面”。
-   **强制投屏：** 开启后，无论小屏幕当前在哪个页面（比如在“时间”页面），只要API服务器收到投屏指令，它就会强制覆盖显示投屏内容。停止投屏后，自动回到原来的页面。这个功能非常适合需要“消息弹出”的场景，比如有新邮件或新订单时，在副屏上闪现提醒。
-   **附加接入协议：** 除了标准的HTTP协议，软件还支持TCP、UDP、热文件夹等多种方式接入。比如“热文件夹”功能，您只需要把一张图片拖放到软件目录下的`hotfolder`文件夹里，它就会立刻显示在小屏幕上，像操作U盘一样简单！
-   **屏幕序号检测：** 当您连接了多块屏幕，分不清哪个是“屏幕1”、哪个是“屏幕2”时，点击此按钮，所有屏幕会同时显示自己的编号，一目了然。

## 第三部分：高级开发指南（API文档与架构分析）

本章节专为开发者、系统集成人员和高级用户准备，提供技术深度的详细说明。

### 第一章：本地API服务器完全手册

API服务器是软件可扩展性的核心。它默认监听 `http://127.0.0.1:8632`。

#### 1.1 认证（Token）
如果设置了访问令牌，所有API请求都需携带：
-   **HTTP Header:** `X-API-Token: YOUR_TOKEN`
-   **Query Parameter:** `?token=YOUR_TOKEN`

#### 1.2 通用约定
-   所有 `POST` 请求体均为 `application/json`。
-   所有接口（除非特别说明）都支持一个可选参数 `"device": "屏幕1"`，用于指定目标屏幕。
-   成功响应通常包含 `"ok": true`。
-   您可以通过 `GET /api/openapi.json` 获取一份符合OpenAPI 3.0规范的机器可读文档，用于自动生成客户端SDK。

#### 1.3 核心投屏接口

**1. 投屏整帧图像**
```http
POST /api/screen
Content-Type: application/json
{
  "image": "base64编码的PNG/JPG数据",
  "fit": "contain", // 可选: contain, stretch, cover
  "device": "屏幕2"
}
```
-   **场景：** 将一张电脑截图或图片推送到副屏。

**2. 投屏原始RGB888数据（高性能）**
```http
POST /api/screen/raw
Content-Type: application/octet-stream
```
-   **Body:** 纯二进制数据，长度为 `SHOW_WIDTH * SHOW_HEIGHT * 3` 字节。
-   **场景：** 如果您在写一个游戏或实时图像处理程序，可以用这种方式实现超低延迟的视频流。

**3. 投屏文本**
```http
POST /api/text
{
  "text": "你好，世界！",
  "font_size": 24,
  "color": "#FFA500",
  "align": "center",
  "background": "#000000"
}
```

**4. 多图轮播**
```http
POST /api/slideshow
{
  "images": ["base64_img1", "base64_img2"],
  "interval": 5.0
}
```

**5. 停止投屏 & 清屏**
```http
POST /api/stop
POST /api/clear
```
-   **区别：** `/stop` 会清空投屏帧并切回API投屏页（或强制投屏模式下的原页面）； `/clear` 仅清空内容。

#### 1.4 控制与查询接口

**1. 切换页面**
```http
POST /api/page
{
  "page": "时间"  // 或 "1"，即PCTIME_PAGE_ID
}
```

**2. 模拟按键**
```http
POST /api/key
{
  "action": "下翻页" // 可选: 下翻页/上翻页/切换方向/无
}
```

**3. 获取状态信息**
```http
GET /api/status
```
-   **返回：** 所有设备连接状态、当前页面、投屏状态等综合信息。

**4. 修改配置**
```http
POST /api/config/set
{
  "marquee_text": "新跑马灯内容",
  "fps_var": 15
}
```
-   **注意：** 只能修改白名单内的配置项，如 `marquee_text`, `weather_city`, `fps_var` 等。

**5. 获取屏幕截图**
```http
GET /api/screenshot?device=屏幕1
```
-   **返回：** 当前屏画面的PNG和RGB888格式的base64数据。

#### 1.5 WebSocket实时通道
-   **地址：** `ws://127.0.0.1:8632/ws`
-   **功能：**
    -   发送**文本帧**：内容为JSON命令，与HTTP的`/api/screen`等接口完全一致。
    -   发送**二进制帧**：内容为原始RGB888数据，与`/api/screen/raw`等效。
-   **场景：** 建立长连接，实现低延迟、高频率的实时视频流推送。

#### 1.6 其他接入协议一览
| 协议 | 地址 | 格式 | 场景 |
| :--- | :--- | :--- | :--- |
| **TCP** | `127.0.0.1:8633` | JSON行，用 `\n` 分隔 | 为C/C++、Java等语言提供简单接入。 |
| **UDP** | `127.0.0.1:8634` | JSON数据报 | 适合发送不要求严格可靠性的“状态”信息。 |
| **热文件夹** | `程序目录/hotfolder/` | 放入图片(.png)或文本(.txt) | 最“傻瓜化”的操作方式。 |
| **命名管道** | `\\.\pipe\MSU2_MINI_V2_api` | JSON行 | Windows下进程间通信（IPC）的高效方式。 |
| **ZeroMQ** | `tcp://127.0.0.1:8635` | REP/REQ模式 | 为分布式系统集成提供便利。 |

### 第二章：开发者核心指南（代码架构与扩展）

此部分面向计划修改源码或进行二次开发的开发者。

#### 2.1 技术栈总览
-   **界面框架：** PySide6 (Qt for Python) - 提供跨平台、现代化的GUI。
-   **核心逻辑：** Python 3.10+
-   **硬件通信：** pyserial - 通过串口协议与副屏硬件通信。
-   **图像处理：** PIL/Pillow, numpy, opencv-python - 负责图像的缩放、裁剪、编码与解码。
-   **系统监控：** psutil - 获取CPU、内存、磁盘、网络等系统信息。
-   **硬件传感器：** LibreHardwareMonitor (通过pythonnet调用) - 获取CPU/GPU温度、风扇转速等深层硬件数据。

#### 2.2 核心类与职责

| 类名 | 文件位置 | 核心职责 |
| :--- | :--- | :--- |
| `ScreenDevice` | 主文件 | **灵魂类**。代表一块物理屏幕，管理其串口、状态、配置、截图线程和渲染状态机。所有多屏隔离逻辑都在此。 |
| `UI_Page` | 主文件 | 整个PySide6界面的构建者。负责所有控件的布局、信号槽连接和UI状态管理。 |
| `sys_config` | 主文件 | 所有可持久化配置的集合。每个`ScreenDevice`都有一个独立的`sys_config`实例。 |
| `MiniMarkParser` | 主文件 | “自定义显示”功能的**模板引擎**。解析类似`p Hello World`这样的文本命令，并将其渲染成图像。 |
| `ApiHandler` | 主文件 | 处理所有HTTP/WebSocket API请求。是外部程序控制副屏的入口。 |

#### 2.3 线程模型
软件大量使用多线程来避免界面卡顿，理解其模型对二次开发至关重要。

1.  **主线程 (UI Thread):** 负责运行PySide6事件循环，处理所有界面交互。严禁在此线程执行耗时操作。
2.  **Daemon线程 (`daemon_task`):** **核心调度线程**。它不断循环，遍历所有已连接的`ScreenDevice`，并调用其状态机进行页面渲染。
3.  **设备线程 (per device):**
    -   **截图线程 (`screen_shot_task`):** 负责捕获屏幕、摄像头或窗口图像。
    -   **处理线程 (`screen_process_task`):** 负责将截图线程的图像进行缩放、色彩空间转换（RGB888 -> RGB565），并压入发送队列。
4.  **Manager线程 (`manage_task`):** 专门负责读取物理按键的ADC值，实现单击/双击/长按的检测和响应。
5.  **后台任务线程:** 用于抓取天气、热搜、网络延迟等，避免阻塞主渲染循环。

#### 2.4 如何添加一个新的显示页面（扩展指南）

这是最常用的二次开发场景。假设我们要添加一个“今日名言”页面。

1.  **定义页面ID：** 在文件顶部的常量区，添加一个新ID，如 `QUOTE_PAGE_ID = 27`。
2.  **注册页面名称：** 在 `PAGE_ID_CN` 和 `PAGE_ID_EN` 字典中添加映射，如 `QUOTE_PAGE_ID: "今日名言"`。
3.  **实现渲染函数：** 在文件的“各显示页面”区域，实现一个函数 `show_quote()`。
    -   函数内部需要从网络或本地文件获取一句名言。
    -   使用 `PIL` 在 `(SHOW_WIDTH, SHOW_HEIGHT)` 的画布上绘制文字。
    -   最后调用 `_safe_send_rgb888(your_rgb888_array)` 将图像发送到屏幕。
4.  **注册到状态机：** 找到 `MSN_Device_1_State_machine` 函数，在 `elif` 分支链中，添加一个新的分支：
    ```python
    elif config_obj.state_machine == QUOTE_PAGE_ID:
        show_quote()
    ```
5.  **（可选）添加配置项：** 如果您想让用户自定义名言来源或刷新时间，可以在 `sys_config` 类中添加新属性，并在“设置”页面的“页面内容”标签下，为其添加对应的UI控件。

### 附录B：常见问题解答 (FAQ)

1.  **问：软件提示“设备未连接”，怎么办？**
    -   答：首先检查USB线是否插好。然后尝试点击“刷新”按钮。如果还不行，可能是驱动程序未安装，请搜索并安装CH340/CP2102驱动。最后，检查您的小屏幕是否被其他软件（如串口调试助手）占用了。

2.  **问：为什么我看不到CPU温度等硬件信息？**
    -   答：大部分硬件传感器信息需要管理员权限才能读取。请**右键点击程序图标，选择“以管理员身份运行”**。

3.  **问：“自定义显示”的模板语法看不懂，怎么办？**
    -   答：不用担心！软件提供了“图形化编辑”功能。您可以在“自定义内容”对话框中切换到“图形化编辑”标签页，通过点击“添加”、“编辑”按钮，用表单的方式插入文字、数值、图片等元素，软件会自动生成模板代码。

4.  **问：我的API请求为什么返回401错误？**
    -   答：您在“设置 -> API接入”中设置了访问令牌。请在您的HTTP请求头（Header）中添加 `X-API-Token: 您的令牌`，或在URL中添加查询参数 `?token=您的令牌`。

5.  **问：如何让多块屏幕显示不同的内容？**
    -   答：首先确认软件识别了多块屏幕（顶部设备栏会显示“屏幕1”、“屏幕2”）。然后，**点击对应的屏幕标签页**（如“屏幕2”），在其中进行的任何页面切换和设置，都只会作用于“屏幕2”。配置会自动保存，即插即用。

6.  **问：我的屏幕是240x240分辨率，软件支持吗？**
    -   答：支持。软件会在连接时自动尝试检测屏幕分辨率。您也可以在“主控”标签页的“屏幕分辨率”下拉框中，手动选择 `240x240 (1.54寸)`。
