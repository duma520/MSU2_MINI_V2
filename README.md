## 一、 写给所有用户：前言与概述

### 1.1 这是什么？
这是一款专为USB小屏幕（如常见的1.3寸、1.54寸、2.4寸等SPI接口屏幕模块）设计的电脑端配套软件。它通过USB虚拟串口与屏幕通信，将您的电脑变成一个**强大的信息显示与控制中心**。

简单来说，它能把一个几厘米大的小屏幕，变成：
*   电脑的**性能监控仪表盘**（CPU、内存、网络速度）。
*   一个**桌面小工具集**（时钟、番茄钟、待办事项、股市行情、微博热搜）。
*   电脑桌面的**无线投屏器**（或局部放大镜）。
*   一个可由程序员**任意编程控制的DIY显示屏**。

## 二、 新手入门：从零开始（10分钟上手）

### 2.1 硬件准备与连接
1.  **设备清单**：确保你有一个支持串口通信的SPI屏幕模块（常见主控如CH32V、STM32）和Micro-USB/Type-C数据线。
2.  **物理连接**：将数据线一端插入屏幕模块，另一端插入电脑的USB接口。屏幕通常会上电亮起（可能显示默认Logo）。

### 2.2 驱动安装（Windows系统）
> **注意**：屏幕通常使用CH340/CH343等USB转串口芯片，需要安装驱动。

1.  如果屏幕插入后电脑没有自动识别（在设备管理器中显示为“未知设备”或带黄色感叹号），请下载并安装CH340/CH343驱动。
2.  安装成功后，在电脑“设备管理器” -> “端口 (COM和LPT)”中，会看到一个“USB Serial Port (COMx)”（例如COM3）。**请记住这个COM端口号，后续排查会用上。**

### 2.3 软件下载与启动
1.  从GitHub Release页面下载最新版的 `.exe` 可执行文件（无需安装，解压即用）。
2.  双击运行 `MSU2_MINI_V2.exe`。
3.  **首次启动**：如果Windows防火墙弹出提示，请允许访问（用于API功能）。软件启动后界面如下图。

### 2.4 认识主界面（主控台）
启动后，您会看到如下主界面。我们将其分为几个区域便于理解：

*   **① 设备状态栏**：显示当前连接的屏幕（屏幕1/2/...）和连接状态（绿色=已连接，红色=未连接）。
*   **② 控制区**：上下翻页、页面下拉选择、屏幕方向调整。这是最常用的切换面板。
*   **③ 烧录区**：用于将图片或固件写入屏幕的Flash芯片（烧录后断电不丢失）。
*   **④ 参数调节区**：调整文字颜色、屏幕刷新率(FPS)、动图播放速度等。
*   **⑤ 信息/日志输出区**：显示程序运行状态、错误信息或API调试日志。
*   **⑥ 设置/工具标签**：包含详细的设置、自定义内容编辑、配色方案、API配置和设备信息查看。
*   **⑦ 实时预览窗**：显示当前副屏实际显示的内容（需在设置中开启“实时预览”）。

## 三、 基础操作指南（小白也能轻松玩转）

### 3.1 切换显示页面
*   **方式一（按钮）**：点击“▲上翻”或“▼下翻”按钮。
*   **方式二（下拉菜单）**：在下拉框中选择你想要的页面，如“时间”、“网络流量”等。
*   **方式三（实体按键）**：如果您的屏幕模块上有触摸按键，单击/双击/长按可以进行翻页（可在设置里自定义映射）。

### 3.2 调整文字颜色与屏幕方向
*   **更改文字颜色**：通过拖动 **R (红) / G (绿) / B (蓝)** 滑块，可以改变时钟、系统状态等页面的文字颜色。旁边的“预设颜色”下拉框提供了丰富的快捷选色。
*   **调整屏幕方向**：在“显示方向”下拉框中，可以选择正向、反向、水平/垂直镜像或90°旋转，以适应不同的安装角度。

### 3.3 烧录图片/动图到设备（Flash）
> **说明**：烧录是将图片或固件保存到屏幕内置Flash芯片的过程，即使断电或重新连接软件，这些内容依然存在（适合做静态Logo或背景）。

1.  **准备背景**：在“选择背景图像”中浏览一张图片（支持PNG/JPG/BMP等），然后点击“烧写”。程序会自动裁剪缩放为160x80并写入Flash。
2.  **准备动图**：在“选择动图文件”中选择一个GIF动图，点击“烧写”。程序会将其拆解为36帧写入Flash。
3.  **切换页面**：烧录完成后，将页面切换至“动图”或“单个相册图片”即可看到效果。

### 3.4 屏幕镜像（投屏电脑屏幕）
1.  在“屏幕镜像窗口”下拉框中，选择您要投屏的软件窗口（如浏览器、代码编辑器）。
2.  软件会实时抓取该窗口画面并缩放显示在副屏上。
> **小技巧**：如果窗口最小化或黑屏，请确保窗口未被完全最小化，或者启用“放大镜模式”（在设置-屏幕镜像中）截取鼠标周围区域。

## 四、 进阶功能详解（释放全部潜能）

### 4.1 丰富的系统监控页面

#### 4.1.1 硬件详情与仪表盘
*   **硬件详情**：在设置中选择监控类型（温度、风扇、电压、负载），可自由选择具体传感器（CPU核心、显卡等），数据超过一屏自动滚动翻页。
*   **仪表盘**：以半圆形进度条展示CPU/内存/GPU/上传下载等数据。颜色和显示项目均可自定义，支持传感器自由选择（包括CPU温度、风扇转速等）。

#### 4.1.2 网络流量与磁盘读写
*   **网络流量**：显示实时上传/下载速度，以柱状图展现流量变化。**经典/自定义**模式可分别调整上下行文字颜色和柱状图颜色。
*   **磁盘读写**：支持**经典/经典2/网速样式**三种布局。经典2布局仿网络流量界面，颜色自动跟随网络流量配色，视觉统一。

#### 4.1.3 进程与热搜
*   **进程TOP**：显示当前占用内存最高的几个进程及其内存占用（默认5个）。
*   **热搜**：支持显示微博实时热搜榜（需联网）。可配置每页条数、字体自适应（自动根据最长文本缩放到一行显示）、长文本滚动字幕（速度可调）、自动刷新间隔。

### 4.2 生产力工具页面

#### 4.2.1 番茄钟与倒计时
*   在设置-页面内容-时间中设置工作时长（默认25分钟）。
*   切换到“番茄钟”页面，屏幕上会显示倒计时。短按按键（或点击界面）可**暂停/继续**，长按/双击可**重置**当前倒计时。

#### 4.2.2 纪念日与待办事项
*   在设置-页面内容-纪念日/待办中输入事项。格式：`名称|MM-DD`（纪念日）。
*   切换页面后，屏幕会显示距离下一个纪念日还有几天，或列出待办清单。

#### 4.2.3 世界时钟与农历
*   **世界时钟**：在设置中配置时区（例：`纽约|-5,伦敦|0`）。页面会轮播显示各城市当前时间。
*   **农历**：直接切换到“农历日期”页面，自动显示当天农历、天干地支和生肖。

### 4.3 自定义显示（MiniMark模板引擎）
这是软件的核心亮点之一，您可以用它绘制任何想要的界面。

#### 4.3.1 图形化编辑器（所见即所得）
1.  点击主界面“自定义内容”按钮。
2.  切换到 **“图形化编辑”** 标签页。
3.  左侧列表列出了当前界面的所有元素（文本、矩形、图片等）。
4.  **操作**：
    *   **添加**：点击下方“添加文本/矩形/图片”等按钮，在弹出的对话框中填入内容。
    *   **编辑**：双击列表中的元素，修改其参数（如文本内容、坐标、颜色）。
    *   **排序**：使用“上移/下移”调整元素图层顺序（先画的在底层）。
    *   **预览**：右侧窗口实时显示最终效果。
5.  点击“应用”即可将设计推送到副屏。

#### 4.3.2 代码模式（高手进阶）
> 如果您懂一些编程思维，可以直接在“显示多项数值”标签页的文本框中编写模板代码。

**MiniMark基础指令速查：**
```python
# 示例：制作一个带有CPU和内存数值的界面
f resource/Orbitron-Bold.ttf 20    # 设置字体为Orbitron，字号20
c #FFA500                         # 设置颜色为橙色
m 8 8                              # 移动到坐标(8,8)
p CPU Usage:                       # 绘制文本
t 8 0                              # 向右移动8像素
v 1                                # 绘制第1个传感器数值（需先在界面选择）
m 8 40                             # 移动到第二行
c #00CCFF                         # 改颜色为青色
p Memory:
t 8 0
v 2 {:.1f}%                       # 绘制第2个数值，保留1位小数
```
*更多命令（画矩形、线条、圆形、GIF动图）请参考软件内“说明”按钮或本文高阶部分。*

#### 4.3.3 模板库与导入导出
*   **预设模板**：图形化编辑器中内置了“大字时钟”、“监控面板”等经典模板，一键套用。
*   **导入/导出**：您可以导出自己设计的模板为 `.txt` 文件，分享给其他用户或备份。

### 4.4 个性化设置

#### 4.4.1 配色方案系统
*   **位置**：设置 -> 配色方案。
*   **功能**：内置260+套色系（马卡龙、赛博朋克、传统国色等）。
*   **使用**：在“网络流量”、“磁盘读写”、“仪表盘”等页面的颜色选择器旁，点击“配色方案”下拉框，选择一套方案，该页面的各颜色位置会自动使用该方案的颜色。
*   **自定义**：您可以修改任意颜色位置的色值，然后点击“存为新方案”，将当前组合保存为一套全新的配色方案。

#### 4.4.2 按键自定义映射
*   **位置**：设置 -> 按键。
*   **功能**：配置屏幕实体按键（单击、双击、长按）对应的操作（下翻页、上翻页、切换方向、无操作）。

#### 4.4.3 自动翻页与息屏待机
*   **自动翻页轮播**：设置一个时间间隔（如5秒），软件会自动在您定义的所有页面（仅主控页面列表里的页面）之间循环切换。
*   **无操作息屏**：设置超时时间（如300秒），键盘鼠标无操作后副屏自动黑屏。触摸按键或点击软件界面即可唤醒。

## 五、 外部世界接入：API投屏（程序员的狂欢）

### 5.1 什么是API投屏？能用来做什么？
该工具内置了一个本地HTTP/WebSocket服务器。这意味着**您自己编写的程序**（Python脚本、网页、手机APP等）可以通过网络请求，把任何数据（文本、实时图像）发送到副屏上显示。

**应用场景举例：**
*   **量化交易**：用Python脚本实时抓取股票/加密货币价格，在副屏显示盈亏和K线走势图。
*   **物联网状态**：将树莓派/Arduino采集的温湿度数据推送到副屏。
*   **游戏/直播**：通过OBS插件将弹幕、点赞数推送到副屏。
*   **自定义仪表**：用代码绘制复杂的雷达图或波形图，通过`/api/screen`接口实时更新。

### 5.2 开启API服务
1.  点击“设置” -> “API接入”标签页。
2.  勾选“启用 API 投屏服务器”。
3.  **端口**：默认为8632，可按需修改。
4.  **访问令牌(可选)**：设置一个密码，防止局域网内其他人乱调用（请求时需携带 `X-API-Token` 头）。
5.  开启后，打开浏览器访问 `http://127.0.0.1:8632` 即可看到投屏控制台和交互测试界面。

### 5.3 API接口速查表
> **基础URL**: `http://127.0.0.1:8632`

#### 5.3.1 基础信息查询 (`GET /api/info`)
获取设备状态、版本、当前页面、屏幕分辨率等信息。
```json
// 返回示例
{
  "ok": true,
  "name": "MSU2_MINI_V2",
  "version": "4.6.0",
  "screen": {"width": 160, "height": 80},
  "connected": true,
  "page": "API投屏"
}
```

#### 5.3.2 投屏整帧图像 (`POST /api/screen`)
将一张完整的图片显示到副屏。支持三种方式传入图像：
1.  **`image`**：Base64编码的PNG/JPG文件（最常用）。
2.  **`rgb888`**：Base64编码的RGB888原始像素字节流。
3.  **`pixels`**：扁平数组，需配套`width`和`height`参数。
4.  **`fit`**：显示方式 (`contain`完整显示 / `stretch`拉伸填满 / `cover`裁剪填充)。
```json
POST /api/screen
{
    "image": "data:image/png;base64,iVBORw0KGgo...",
    "fit": "contain"
}
```

#### 5.3.3 文本投屏 (`POST /api/text`)
直接在副屏上显示文字。
```json
POST /api/text
{
    "text": "Hello World!",
    "font_size": 24,
    "color": "#FF6600",
    "x": 10,
    "y": 20,
    "align": "center", // left, center, right
    "background": "#000000"
}
```

#### 5.3.4 切换页面与清屏 (`POST /api/page` & `/api/clear`)
```json
POST /api/page
{ "page": "时间" }  // 或使用页面ID

POST /api/clear
{ }  // 清空投屏帧，显示API等待界面
```

#### 5.3.5 多屏投屏（指定设备）
如果您连接了多个屏幕，所有投屏接口均支持 `device` 参数。
```json
POST /api/text
{
    "text": "这是屏幕2",
    "device": "屏幕2"  // 通过 GET /api/devices 获取可用设备名
}
```

### 5.4 WebSocket实时通道
对于高频、低延迟的数据推送（如动态波形图），使用WebSocket比HTTP轮询更高效。
*   **地址**：`ws://127.0.0.1:8632/ws`
*   **二进制帧**：直接发送 `W*H*3` 字节的原始RGB888数据，会被立即解码显示。
*   **文本帧 (JSON)**：支持与REST API相同的命令（`type`字段）：
    ```json
    {"type": "text", "text": "Hello via WS"}
    {"type": "clear"}
    {"type": "screen", "image": "base64..."}
    ```

### 5.5 代码举例
**Python (使用 requests 库)**
```python
import requests
import base64

# 1. 投屏文本
resp = requests.post("http://127.0.0.1:8632/api/text", json={
    "text": "Python API 调用成功!",
    "color": "#00FF00"
})
print(resp.json())

# 2. 投屏图片
with open("my_pic.png", "rb") as f:
    b64 = base64.b64encode(f.read()).decode()
resp = requests.post("http://127.0.0.1:8632/api/screen", json={
    "image": b64,
    "fit": "stretch"
})
print(resp.json())
```

**JavaScript (浏览器 或 Node.js)**
```javascript
// 通过WebSocket实时推送画面（假数据）
const ws = new WebSocket('ws://127.0.0.1:8632/ws');
ws.onopen = () => {
    setInterval(() => {
        // 生成随机的 RGB 数据（160 * 80 * 3）
        const width = 160, height = 80;
        const raw = new Uint8Array(width * height * 3);
        for (let i = 0; i < raw.length; i++) {
            raw[i] = Math.random() * 255;
        }
        ws.send(raw.buffer); // 直接发送二进制数据！
    }, 100);
};
```

## 六、 高阶技巧与故障排除

### 6.1 命令行参数
您可以通过快捷方式或命令行启动时携带参数：
*   `--page 时间`：软件启动后直接切换到“时间”页面。
*   `--com COM3`：强制指定串口为COM3，避免自动识别到错误的设备。
*   `-hide`：启动后自动最小化到系统托盘。

### 6.2 多屏独立配置
当您同时连接多个USB副屏时：
*   每个屏幕根据其USB序列号或COM端口，会自动生成独立的配置文件 `MSU2_MINI_<SN>.json`。
*   每个屏幕可以设置不同的页面、方向、配色方案，互不干扰。
*   在软件顶部的“已连接设备”下拉框中，您可以选择当前正在操作的是哪一个屏幕。

### 6.3 常见问题FAQ
**Q：软件显示“设备未连接”，怎么办？**
*   A：1. 检查USB线是否插好，屏幕是否通电。2. 检查驱动是否安装（见2.2节）。3. 尝试更换USB接口。4. 检查是否有其他软件（如串口助手）占用了该COM口。

**Q：屏幕画面出现倾斜/斜切/花屏？**
*   A：这是由于串口传输丢包或命令流错位导致。软件已有完善的容错机制，如果在切换页面或窗口后出现，请点击“检测屏幕”按钮强制重置LCD方向，或重新拔插USB设备。

**Q：屏幕镜像窗口黑屏/显示桌面？**
*   A：1. 请确保您选择的窗口不是最小化状态（可置于后台但不要最小化）。2. 对于部分全屏游戏或UWP应用（如Netflix），Windows的PrintWindow API无法捕获，可以尝试在设置-屏幕镜像中开启“放大镜模式”来截取鼠标周围区域。

**Q：如何重置所有配置？**
*   A：关闭软件，删除程序目录下的 `config` 文件夹中的所有 `.json` 文件，重启软件即可恢复出厂设置。
