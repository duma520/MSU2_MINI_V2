## 第一章 初识USB副屏工具

### 1.1 这是什么？—— 核心功能一句话概括

**USB副屏工具（MSU2_MINI_V2）** 是一款运行于Windows平台的免费开源软件，通过USB接口连接、控制并驱动各类小型LCD显示屏（如MSU2_MINI系列、某些定制USB屏幕），使其能够实时显示电脑的系统状态、时间、网络流量、桌面镜像、摄像头画面、自定义动画或复杂的数据仪表盘。

**简单来说**：它把一块小小的USB屏幕变成了你电脑的“专属信息中心”或“装饰性副屏”。

### 1.2 我能用它做什么？—— 八大典型应用场景

1.  **电脑硬件监控面板**：实时显示CPU占用率、内存使用率、磁盘占用率、电池电量，让系统状态一目了然。
2.  **桌面艺术时钟**：配合自定义背景，显示炫酷的大字时间，作为桌面的数字装饰。
3.  **性能测试专用显示器**：在玩大型游戏或进行视频渲染时，用它监控关键硬件参数，不遮挡主屏幕。
4.  **屏幕镜像/扩展**：将主屏幕的某个窗口（如聊天软件、视频播放器）镜像到小屏幕上，实现多任务操作。
5.  **网络流量仪表盘**：以图表形式实时展示上传和下载速度，直观了解网络状况。
6.  **个人相册/滚动海报**：在小屏幕上循环播放您喜欢的图片，打造个性化桌面摆件。
7.  **主播/直播辅助屏**：用于显示直播间的弹幕、观众数、礼物信息等，放置在摄像头附近以便查看。
8.  **开发/创客项目显示终端**：通过自定义MiniMark模板，编程显示Arduino、树莓派等设备传来的传感器数据。

### 1.3 系统要求与硬件支持

- **操作系统**：Windows 10 / Windows 11（推荐64位）。需要以**管理员权限**运行以获得完整的硬件监测功能。
- **硬件**：
  - 一个兼容的USB小屏幕设备（如MSU2_MINI V2，或其他采用CH55x系列芯片的USB屏幕）。
  - 电脑主板需有可用的USB-A或USB-C接口。
  - **注意**：此工具主要针对基于特定芯片（如WCH CH552等）的USB屏幕设计，并非所有USB显示器都兼容。您的设备应与“MSU2_MINI”系列在硬件上兼容。
- **软件**：
  - 需要安装设备对应的**USB驱动程序**（详见2.2节）。
  - 推荐安装 [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework) 或更高版本以确保依赖库正常运行。

## 第二章 快速上手（5分钟从零开始）

我们假设您已经拿到了一块USB小屏幕，并想立刻开始使用。本章将引导您完成从连接到显示的第一个完整流程。

### 2.1 第一步：连接你的USB小屏幕

将USB小屏幕通过数据线连接到电脑的USB接口。此时，屏幕可能会亮起（显示默认图案或黑屏），并且Windows会发出设备插入的提示音。

**注意**：如果屏幕没有任何反应，请检查USB接口和数据线是否正常。

### 2.2 第二步：安装驱动程序（重中之重！）

这是最关键的一步。为了让电脑把小屏幕识别为一个可以通信的设备，必须安装正确的驱动程序。

1.  **打开设备管理器**：
   - 右键点击“开始”按钮，选择“设备管理器”。
   - 或者在搜索栏输入“设备管理器”并打开。

2.  **找到未知设备**：
   - 在设备管理器的列表中，找到带有黄色感叹号的“未知设备”，或者可能显示为“USB Composite Device”但带有警告标志。
   - 如果设备被识别为“NanoKVMPro”或类似名称，这也是正常现象，仍需安装驱动。

3.  **更新驱动程序**：
   - 右键点击该设备，选择“**更新驱动程序**”。
   - 在弹出的窗口中，选择“**浏览我的电脑以查找驱动程序**”。
   - 然后选择“**让我从计算机上的可用驱动程序列表中选取**”。

4.  **选择正确的驱动类型**：
   - 在设备类型列表中，向下滚动，找到并选择“**通用串行总线设备**”或“**标准系统设备**”（不同版本Windows名称可能略有不同）。
   - 在右侧的制造商列表中，选择“**标准系统设备**”或类似选项。
   - 在型号列表中，找到并选择“**USB 复合设备**”。
   - 点击“下一步”，系统将安装驱动程序。

**如果安装失败，提示“驱动程序签名”错误怎么办？**

有时Windows会阻止安装未经数字签名的驱动。请尝试以下方法：

- **方法一（推荐）**：**临时禁用驱动程序强制签名**。重启电脑，在开机时按 `F8` 或 `Shift + 重启` 进入“高级启动选项”，选择“**禁用驱动程序强制签名**”，进入系统后再安装驱动。
- **方法二**：**启用测试模式**。以管理员身份打开命令提示符（CMD），输入命令 `bcdedit /set testsigning on`，重启电脑后再安装驱动。安装完成后，可输入 `bcdedit /set testsigning off` 关闭测试模式。

安装成功后，在设备管理器的“显示适配器”或“通用串行总线设备”下，应该会看到一个新的设备，如“NanoKVM”或“USB Composite Device”，不再有黄色感叹号。

### 2.3 第三步：下载并运行程序

1.  从 [GitHub项目主页](https://github.com/duma520/MSU2_MINI_V2) 的“Releases”页面下载最新的 `MSU2_MINI_V2.zip` 压缩包。
2.  将其解压到一个文件夹（建议放在非中文路径下，如 `D:\MSU2_MINI_V2`）。
3.  双击运行 `MSU2_MINI_V2.exe`。
4.  **重要**：建议右键点击选择“**以管理员身份运行**”，否则CPU、GPU温度等硬件信息可能无法读取。

程序启动后，您会看到一个界面。主窗口左上角会显示“设备未连接”的红底白字标签。

### 2.4 第四步：选择显示页面

在程序的主界面中央，有一个“页面”下拉选择框。点击它，您会看到一系列预设的显示模式，例如：动图、时间、单个相册图片、屏幕镜像等。

程序默认启动后，屏幕会尝试显示默认页面（通常是“屏幕镜像”）。您可以通过点击“▲上翻”、“▼下翻”按钮或直接在下拉列表中选择来切换不同的显示模式，这个操作会立即让USB屏幕切换内容。

**小贴士**：如果屏幕没有反应，请检查程序左下角是否显示“设备已连接”。若显示“设备未连接”，请参考第五章的故障排除。

### 2.5 第五步：第一次烧录（让屏幕显示内容）

“烧写”是将图片或固件写入USB屏幕内部存储芯片（Flash）的过程。**大多数显示模式（如时间、动图、相册）都需要预先烧写内容到屏幕**。

让我们尝试让屏幕显示一张图片：

1.  在“主控”页面，找到“**选择相册图像**”下的文本框，点击右侧的“**选择**”按钮。
2.  从电脑中选择一张您喜欢的图片（支持JPG, PNG, BMP等）。
3.  文件路径会显示在文本框中。
4.  点击旁边的“**烧写**”按钮。
5.  稍等片刻（大约几秒到十几秒），程序下方的信息框会提示“烧写完成”。
6.  然后，在主界面将“页面”切换为“**单个相册图片**”，您的小屏幕就会显示出您选择的图片了！

恭喜您，您已经成功完成了第一次烧写和显示！现在，您可以开始探索所有功能了。

## 第三章 功能详解 —— 从基础到精通

本章将详细分解程序界面的每一个区域和功能，让您知其然更知其所以然。

### 3.1 主控面板：你的指挥中心

主控面板是您与USB屏幕交互的主要界面。

#### 3.1.1 设备连接与状态指示

- **状态标签**：左上角红/绿标签直观显示设备连接状态。
  - **“设备已连接” (绿色)**：表示成功与USB屏幕建立通信，可以进行一切操作。
  - **“设备未连接” (红色)**：表示无法与屏幕通信。请检查USB连接、驱动是否安装成功，或重启软件。
- **信息显示框**：主控面板下方的大文本框，记录了所有操作日志，包括连接信息、烧写进度、错误提示等。是排查问题的重要工具。
- **“隐藏”按钮**：将程序窗口最小化到系统托盘（任务栏右下角）。您可以右键单击托盘图标选择“显示”恢复窗口或“退出”关闭程序。

#### 3.1.2 页面导航与切换

- **“▲上翻” / “▼下翻”**：循环切换显示页面。点击一次，小屏幕内容切换至下一页/上一页。
- **“页面”下拉列表**：直接选择您想切换到的页面，比按键翻页更快。当前激活的页面会被高亮。

**专业提示**：USB屏幕上的物理按键（如果有）也支持单击（下翻）、双击（上翻）、长按（切换方向）。

#### 3.1.3 显示方向控制

- **“显示方向”下拉列表**：您可以在这里选择屏幕的显示方向。支持：
  - 正向 (0°)
  - 反向 (180°)
  - 水平镜像 / 垂直镜像
  - 顺时针90° / 逆时针90°
  这个功能非常实用，方便您根据屏幕的物理摆放位置（如横放、竖放）来调整显示内容，确保内容始终正向显示。

#### 3.1.4 文字颜色自定义

此区域控制所有显示页面中**文字、线条、图表的颜色**。

- **颜色预览框**：直观显示当前选中的颜色。
- **R/G/B滑块**：分别调节红、绿、蓝三色通道的值（0-255），可以混合出任何您想要的颜色。例如：全红(255,0,0)、亮黄(255,255,0)、纯白(255,255,255)、紫色(128,0,255)。
- **预设颜色下拉列表**：快速选择常用颜色，从基础色到“马卡龙”、“霓虹”色系应有尽有，方便设计搭配。

**专业提示**：配合“时间”、“系统状态”等页面使用效果极佳，能让屏幕色彩与您的主机RGB风格或桌面主题保持一致。

#### 3.1.5 高级设置区域

- **动图间隔**：控制GIF动画或36帧连续图片切换的速度。数值越大，动画播放越慢。当设置为较大数值（如5秒以上）时，动图模式就相当于一个幻灯片相册。
- **最大 FPS**：设定“屏幕镜像”和“相机视频”模式的最高刷新率。提高帧率会让画面更流畅，但会占用更多CPU和USB带宽。请根据您电脑的性能和USB2.0/3.0接口的带宽来设置（建议5-30帧）。
- **相机名称**：下拉选择您连接好的USB摄像头。选择后，切换到“相机视频”页面即可实时显示摄像头画面。
- **屏幕镜像窗口**：下拉选择您想要镜像到小屏幕上的窗口。支持所有可见窗口，包括“桌面”和各个“显示器屏幕”。

### 3.2 烧写功能：把内容“刻”进屏幕

#### 3.2.1 什么是“烧写”？

USB小屏幕内部有一块闪存（Flash）芯片，用于存储图片、字体和固件数据。烧写，就是通过USB接口将这些数据写入该芯片的过程。**一旦烧写完成，即使电脑关机或断开连接，当屏幕再次通电时，只要程序不干预，它默认显示的内容也是最后一次烧写进去的图片或固件所决定的内容**。比如，您烧写了一张“LOGO”图片，那么下次屏幕一插上电，可能就会显示这个LOGO。

#### 3.2.2 烧写闪存固件 (.bin)

- **作用**：这通常是设备出厂时或进行重大功能更新时才需要的操作。它烧写的是屏幕的基础控制程序（固件）。**普通用户通常不需要使用此功能，除非您从硬件商家处获得了新的固件升级文件。**
- **操作**：点击“选择”，选中商家提供的 `.bin` 固件文件，然后点击“烧写”。

#### 3.2.3 烧写背景图像

- **作用**：为“时间”模式提供背景图片。您可以将自己喜欢的图片烧写进去，替代单调的纯色背景。
- **支持格式**：几乎所有常见图片格式（JPG, PNG, BMP, GIF等）。
- **操作**：选择一张图片，点击“烧写”。程序会自动将其缩放到屏幕尺寸（如160x80）并转换格式，然后写入Flash的指定位置（页地址3826）。

#### 3.2.4 烧写相册图像

- **作用**：为“单个相册图片”模式提供展示内容。
- **支持格式**：同背景图像。
- **操作**：选择一张图片，点击“烧写”。图像会被写入地址3926。

#### 3.2.5 烧写动图文件

- **作用**：为“动图”模式提供动画素材。这是该工具最强大也最复杂的功能之一。
- **支持两种方式**：
  1.  **直接烧写GIF文件**：选择任意一个 `.gif` 动图文件，程序会自动解析其每一帧，转换成屏幕能识别的格式，并智能计算推荐的播放速度（动图间隔）。
  2.  **烧写36张连续图片**：您可以将36张图片（命名为 `图像名0.jpg`, `图像名1.jpg`... `图像名35.jpg`）放在同一个文件夹，然后选择第一个文件（如 `图像名0.jpg`），程序会自动按顺序加载这36张图片并烧写。
- **操作**：选择GIF或第一张图片序列，点击“烧写”。数据会被写入Flash的起始页地址0。

**专业提示**：动图功能非常耗资源。一个高质量的GIF，其烧写后的数据可能占用上千页（每页256字节）的Flash空间。如果动图太大或帧数过多，可能会超出屏幕的存储容量（1024KB），这时程序会给出警告。

### 3.3 显示模式详解

#### 3.3.1 动图模式
- **显示内容**：播放您通过“烧写动图文件”写入的动画。
- **控制**：通过“动图间隔”调节播放速度，数值越小播放越快。

#### 3.3.2 时间模式（大字时钟）
- **显示内容**：全屏显示当前系统时间（HH:MM），使用大字库字体（ASC64）。
- **依赖**：需要预先烧写“背景图像”作为时钟背景，否则背景为黑色。
- **颜色**：通过“文字颜色”调整数字的颜色。
- **刷新**：每分钟刷新一次，秒数在后台计算。

#### 3.3.3 相册模式
- **显示内容**：显示您通过“烧写相册图像”写入的图片。
- **特点**：静态显示，适合作为桌面摆件展示固定的标识或照片。

#### 3.3.4 屏幕镜像模式
- **显示内容**：实时镜像电脑屏幕上指定窗口或整个桌面的画面。
- **原理**：程序会高速截取目标窗口的画面，经过缩放、裁剪和色彩转换后发送给USB屏幕。
- **设置**：
  - **选择窗口**：在“屏幕镜像窗口”下拉列表中选择。
  - **填充/适应**：
    - **填充**：裁剪画面，使其完全填满小屏幕，但可能会牺牲部分边缘内容。
    - **适应**：保持画面宽高比，完整显示画面，但屏幕上下或左右可能出现黑边。
  - **最大FPS**：控制镜像的流畅度。

#### 3.3.5 相机视频模式
- **显示内容**：显示USB摄像头的实时画面。
- **设置**：在“相机名称”中选择您的摄像头。
- **注意**：此模式与屏幕镜像模式共用帧率和画面缩放设置。

#### 3.3.6 系统状态监控模式
- **显示内容**：以数字形式显示四项关键系统指标：
  - **CPU**：CPU使用率（%）
  - **RAM**：内存使用率（%）
  - **FRQ**：C盘（系统盘）磁盘使用率（%）
  - **BAT**：电池电量（%）（台式机无电池则显示100%）
- **原理**：通过 `psutil` 库实时读取系统性能计数器。
- **权限**：需要以管理员权限运行，否则部分数据可能无法读取。

#### 3.3.7 网络流量监控模式
- **显示内容**：以**文字**显示当前实时上传/下载速度，同时以**柱状图**显示速度变化趋势。
- **原理**：通过 `psutil.net_io_counters()` 计算每秒的流量。
- **颜色**：使用“文字颜色”和固定的图表配色。

#### 3.3.8 自定义模式（一）：两项图表
- **显示内容**：与“网络流量监控”模式布局相同，但数据来源可以自定义。
- **用途**：可以监控任意两个硬件传感器的数值，并以文字+折线图的形式显示。例如，您可以监控 **CPU温度** 和 **GPU温度**。
- **设置**：通过“自定义内容”按钮进入，在“显示两项图表”标签页中，从下拉列表中选择两个您想监控的硬件项目，并为它们起一个显示名称。

#### 3.3.9 自定义模式（二）：完全自定义模板（MiniMark）
这是本工具最具可玩性和专业性的功能。它允许您通过一种名为 **MiniMark** 的简单标记语言，完全自由地设计屏幕显示内容。

- **原理**：您可以编写一个文本模板，像写代码一样指定在屏幕的(x,y)坐标上绘制什么文字、使用什么字体、什么颜色，甚至可以插入图片，或显示实时硬件传感器的数值。
- **示例模板**：
  ```
  c #ff3333          # 将文字颜色设为红色
  f simhei.ttf 16    # 使用黑体，字号16
  m 10 10            # 移动到坐标(10,10)
  p CPU占用：         # 绘制文字“CPU占用：”
  v 1 {:.1f}%        # 绘制第1个传感器的值，格式化为带一位小数的百分数
  ```
  这个简单的模板就可以在屏幕上画出“CPU占用：45.6%”这样的信息。
- **可视化编辑**：在“自定义内容”窗口中，您可以编辑模板代码，并实时在右侧的“效果预览”中看到显示结果，非常方便。您无需反复烧写，所见即所得。
- **高级功能**：
  - 您可以通过 `i` 命令在模板中插入图片（如 `i resource/logo.png`）。
  - `a` 命令可以改变文字的对齐锚点（如 `la` 左对齐，`ra` 右对齐，`ma` 居中对齐）。
  - `v` 命令的 `[]` 内可以填写Python格式字符串，对数值进行格式化。

**更多关于MiniMark语法，请参考[第六章 附录](#chapter-6)的速查表。**

#### 3.3.10 关于模式
- **显示内容**：在屏幕上滚动显示程序版本、作者、开源协议、项目地址等信息，适合展示程序归属。

## 第四章 深入配置与优化

### 4.1 防烧屏机制

OLED屏幕长时间显示静态画面可能会导致“烧屏”现象（即永久性的残影）。本工具内置了防烧屏功能。

- **原理**：每隔30秒，程序会自动将整个显示内容微幅移动1-2个像素（在9个不同方向循环移动）。这种微小的偏移人眼不易察觉，但能有效防止固定像素长时间发光，从而延长屏幕寿命。
- **设置**：在“设置”标签页中，可以启用或禁用此功能。强烈建议保持开启。

### 4.2 屏幕分辨率设置

- **自动检测**：程序启动并连接设备后，会自动尝试读取屏幕的SFR（特殊功能寄存器）信息，以获取屏幕的真实分辨率（如160x80, 128x64等）。这通常在连接成功时自动完成。
- **手动设置**：如果自动检测失败，您可以在“主控”页面底部，通过“屏幕分辨率”下拉列表手动选择或输入您的屏幕型号对应的分辨率。这将确保图像显示比例正确，不发生拉伸或压缩。
- **适用场景**：更换了不同分辨率的USB屏幕，或者程序未能正确识别您的屏幕时。

### 4.3 截图与性能优化

“屏幕镜像”和“相机视频”是资源消耗较大的功能。程序内部使用了高效的流水线处理（截图线程 + 图像处理线程）和帧率控制。

- **性能建议**：
  - 若镜像卡顿，请尝试降低“最大FPS”值。
  - 不要同时开启多个高分辨率窗口的镜像。
  - 使用USB 3.0接口可以获得更好的数据传输性能。

### 4.4 多设备支持

从V2.0版本开始，本工具支持同时连接和管理多块USB小屏幕。

- 在程序顶部栏的“已连接设备”下拉列表中，会显示所有已连接并识别的屏幕。
- 您可以选择不同的屏幕，并为其独立设置显示页面、方向和自定义内容。
- 在“设置”标签页中，可以预览和切换当前操作的目标设备。

## 第五章 故障排除与常见问题

### 5.1 设备无法连接

**现象**：程序状态为“设备未连接”，或串口打开失败。

**解决方案**：
1.  **检查物理连接**：确认USB线连接牢固，尝试更换USB接口或数据线。
2.  **检查驱动程序**：这是最常见的原因。请按照[2.2节](#22-第二步安装驱动程序重点)的指引，重新安装正确的驱动程序。确保设备管理器中没有“未知设备”或带黄色感叹号的设备。
3.  **检查端口占用**：确保没有其他程序（如串口调试工具、其他副屏软件）占用了该USB设备的COM端口。
4.  **重启程序或电脑**：有时系统USB堆栈可能出现短暂故障，重启可以解决。
5.  **管理员权限**：尝试右键点击程序图标，选择“以管理员身份运行”。

### 5.2 屏幕显示异常（倾斜、花屏、颜色不对）

**现象**：显示内容扭曲、颜色像雪花、或图像被拉伸。

**解决方案**：
1.  **检查分辨率设置**：在“屏幕分辨率”中，尝试手动选择和您屏幕匹配的分辨率。
2.  **切换显示方向**：有时方向设置错误也会导致显示混乱，尝试切换几个方向看是否能恢复。
3.  **重新烧写**：Flash中的数据可能损坏。尝试重新烧写一个简单的图片（如背景图像或相册图像），覆盖可能有问题的数据。
4.  **检查USB连接稳定性**：不稳定的连接可能导致数据传输出错。更换高质量的数据线。

### 5.3 烧写失败

**现象**：点击“烧写”后，进度条不动或提示错误。

**解决方案**：
1.  **确认设备在线**：确保程序显示“设备已连接”。
2.  **检查文件路径**：确保图片或固件文件路径没有中文字符或特殊符号，尽量放在纯英文路径下。
3.  **检查文件格式**：确保图片格式是程序支持的常见格式（JPG, PNG, BMP）。对于GIF，确保它是一个有效的动图。
4.  **检查Flash空间**：如果烧写大文件（如高帧数GIF）时失败，可能是文件超过了Flash的存储容量（1024KB）。尝试压缩图片尺寸或减少GIF帧数。

### 5.4 屏幕镜像黑屏或卡顿

**现象**：切换到“屏幕镜像”模式后，小屏幕全黑或画面不动。

**解决方案**：
1.  **检查截图窗口**：确认“屏幕镜像窗口”下拉列表中选择了正确的窗口（如“桌面”或一个具体的程序窗口）。选择了不可见的窗口会导致黑屏。
2.  **降低FPS**：高FPS对系统性能要求高。尝试将“最大FPS”调低至5或10。
3.  **切换截图方式**：对于某些游戏或全屏应用，普通的截图方式可能无效。程序内置了备用的 `mss` 截图方案，在某些窗口黑屏时会自动切换。如果持续黑屏，可以尝试镜像“桌面”而不是特定窗口。

### 5.5 自定义模板显示错误

**现象**：切换到“自定义显示多项数值”页面时，屏幕一片粉色，或显示 `<1>` 等错误信息。

**解决方案**：
1.  **查看错误提示**：在“自定义内容”窗口中，点击“查看模板错误”按钮，会弹出详细的错误信息，指明是哪一行代码或哪个变量出了问题。
2.  **检查传感器权限**：如果变量显示为 `<1>`，很可能是因为程序不是以管理员权限运行，导致无法读取硬件传感器。请关闭程序，以管理员身份重新运行。
3.  **检查模板语法**：仔细核对`v`命令引用的传感器序号（如`v 1`）是否对应了“自定义显示多项数值”标签页中下拉列表选择的项目。
