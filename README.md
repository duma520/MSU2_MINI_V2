整合 https://github.com/dimangopie/just-fun-for-MSU2_MINI 和 https://github.com/dchg43/msu2_mini 的程序。

因为新买的“USB小屏幕0.96寸USB直插式电脑监控小屏”，没有源码，只有exe程序。

https://github.com/dimangopie/just-fun-for-MSU2_MINI 花屏，但是修改一下，也能正常显示，但是退出的时候就一直调频率，退不出来。

https://github.com/dchg43/msu2_mini 能连接，有显示，就是感觉缺点啥。

所以也懒得搞为什么，直接整合一起，再优化，增加一些功能。

## 第一部分：欢迎与导览

### 1.1 这是什么东西？
想象一下，你有一个大电脑，但总觉得少了点“极客范儿”。你有没有见过那种机箱上带个小屏幕，能显示 CPU 温度、时间，甚至还能放个动图？这个程序就是为那种小屏幕准备的“大脑”和“遥控器”。

**一句话定义**：`MSU2_MINI_V2` 是一个运行在 Windows 电脑上的桌面软件，它通过 USB 数据线连接一块物理小屏幕（通常是基于 CH32V 系列芯片的副屏），让你可以在那块小屏幕上**显示任何你想要的东西**。

从显示系统监控数据（CPU、内存、网速），到播放 GIF 动图，再到当第二个显示器用（屏幕镜像），甚至允许其他程序员通过 HTTP/WebSocket 接口给它“投屏”，它都能做到。

### 1.2 核心功能一览（小白版）

- **系统监控**：把电脑的 CPU、内存、硬盘、网络速度实时显示在小屏上。
- **酷炫显示**：播放 GIF 动图、显示大号数字时钟、跑马灯文字。
- **屏幕镜像**：把小屏变成电脑的“放大镜”，可以显示桌面、某个窗口，甚至游戏画面（性能允许下）。
- **数据看板**：如果电脑装了监控软件（LibreHardwareMonitor），可以显示 CPU/GPU 温度、风扇转速。
- **联网信息**：显示实时天气、加密货币价格、微博热搜。
- **开发者神器**：提供网页和 API 接口，可以让你的代码（Python、JavaScript 等）动态控制小屏显示内容。

### 1.3 谁能用？

- **普通玩家**：用来当电脑的“状态仪表盘”，玩游戏时瞄一眼就知道帧率、温度。
- **桌面美化爱好者**：显示时钟、天气、动图，打造个性化桌面。
- **DIY 爱好者**：配合 3D 打印，把屏幕嵌入机箱、键盘或者制作独立桌搭。
- **程序员 / 极客**：通过 API 接口，给智能家居、个人项目做一块专属信息看板。

## 第二部分：零基础快速上手

### 2.1 我该准备什么？

1.  **硬件**：一块 USB 副屏（只要是基于 CH32V 或类似方案的，通常卖家会提供驱动），一根 USB 数据线。
2.  **软件**：本程序 `MSU2_MINI_V2.exe`（从 GitHub Release 下载）。Windows 10/11 系统。

### 2.2 三步开始使用

1.  **连接设备**：将副屏通过 USB 线插入电脑。电脑会自动安装串口驱动（如 CH340/CH343），如果没有，请先安装驱动。
2.  **运行程序**：双击打开 `MSU2_MINI_V2.exe`。
    - 如果遇到安全提示，点击“仍要运行”。
    - 窗口可能会比较小，这是正常的。
3.  **查看连接**：在程序界面的“主控”页，左上角有“设备未连接”或“设备已连接”的提示。
    - 如果显示“未连接”，点击顶部的“刷新”按钮，或重新插拔 USB 线。

### 2.3 我的第一张画面

- **显示一张图片**：
    1.  在程序界面的“烧写”区域（通常是中间偏下），找到“选择背景图像”，点击“选择”。
    2.  挑一张你喜欢的图片（JPG, PNG 都行）。
    3.  点击“烧写”，等待进度条走完（只需要几秒）。
    4.  在“主控”页的上方，找到“页面”下拉框，选择“时间”。（如果是第一次，可能需要点一下“上翻/下翻”按钮刷新）。
    5.  现在，小屏幕应该显示一张带有时间的图片了！

- **切换显示内容**：
    - 点击主控页上的“▲上翻”或“▼下翻”按钮，可以在“动图”、“时间”、“屏幕镜像”、“系统监控”等页面之间切换。

## 第三部分：核心功能详解（按页面分类）

下面列出了所有可选的显示页面，以及它们的用途和设置位置。

### 3.1 视觉娱乐类

- **动图**：播放预先烧录到屏幕 Flash 里的 GIF 图片（最多支持 36 帧）。
    - *设置*：在“主控”页调整“动图间隔”数值。
- **时间**：显示大号数字时钟（HH:MM）。
    - *设置*：在“主控”页调整“文字颜色”（滑块或色盘）。
- **相册图片**：显示一张烧录好的静态图片。
- **文字跑马灯**：让一段文字在小屏上循环滚动。
    - *设置*：在“设置 → 页面内容 → 文字跑马灯”中修改文本、字号、颜色和滚动速度。

### 3.2 系统监控类（专业向）

- **电脑状态监控**：显示 CPU、内存、电池、硬盘的百分比占用。
- **网络流量监控**：以图表和数字形式显示实时上传/下载速度。
    - *设置*：可独立设置上传/下载文字颜色和柱状图颜色（“设置 → 监控显示 → 网络流量”）。
- **磁盘读写速率**：监控硬盘的读写速度。
    - *设置*：提供“经典”、“经典2”、“网速样式”三种布局，颜色均可自定义。
- **进程 TOP**：按内存占用显示排名最前的进程（如 `Chrome 350MB`）。
    - *设置*：在“设置 → 监控显示 → 进程”中调整显示数量。
- **硬件详情**：显示 CPU/GPU 温度、风扇转速、电压等（需要管理员权限和 LibreHardwareMonitor 后台）。
    - *设置*：可以自由勾选想要监控的传感器类型（温度/风扇/负载等）。

### 3.3 数据信息类

- **天气**：显示指定城市的天气和温度（数据源：wttr.in）。
    - *设置*：在“设置 → 页面内容 → 天气与行情”中输入城市名（支持中文，如“北京”）。
- **行情**：显示加密货币价格（数据源：Gate.io）。
    - *设置*：在“设置 → 页面内容 → 天气与行情”中输入交易对（如 `BTCUSDT,ETHUSDT`）。
- **热搜**：显示微博热搜榜。
    - *设置*：可调整显示条数、字体大小（自动或手动）、翻页间隔和自动刷新时间。
- **网络延迟 (Ping)**：显示到指定服务器的网络延迟。
    - *设置*：在“设置 → 页面内容 → 天气与行情”中修改测试目标 IP 或域名。
- **世界时钟**：同时显示多个时区的时间。
    - *设置*：在“设置 → 页面内容 → 时间”中编辑时区列表（格式：`名称|偏移`，如 `伦敦|0`）。
- **农历日期**：显示当前公历日期对应的农历日期、天干地支和生肖。

### 3.4 工具与开发类

- **屏幕镜像**：将电脑桌面或特定窗口的内容实时投射到小屏。
    - *用途*：监控后台程序、放大局部画面（带缩放功能）、游戏辅助。
    - *设置*：在“主控”页选择“镜像窗口”；在“设置 → 屏幕镜像”中开启“镜像局部放大（跟随鼠标）”。
- **API 投屏**：让其他程序（网页、手机应用等）通过网络控制小屏。
    - *这是本软件的核心高级功能，详见第七章。*

## 第四部分：专业配置与自动化

### 4.1 显示方向与分辨率
- **显示方向**：在主控页的下拉框中，可以选择 0°、90°、180° 等旋转方向，方便你按任意角度安装屏幕。
- **分辨率**：如果屏幕显示不全或变形，在“设置 → 通用”或主控页底部，可以手动选择分辨率（如 160x80, 240x240），也可以点击“检测屏幕”让程序自动识别。

### 4.2 自动化功能（懒人福音）
- **自动翻页轮播**：开启后，程序会自动在多个页面间循环切换（如：时间→监控→天气→时间...）。
    - *设置*：“设置 → 自动化”中开启，并设置切换间隔。
- **息屏待机**：设定时间（比如 60 秒），无按键操作后自动黑屏，按副屏上的物理按键或切页即可唤醒。
- **防烧屏**：OLED 屏幕长时间固定画面容易留下残影。开启后，画面会每隔 30 秒微动 1-2 个像素，有效延长屏幕寿命。

### 4.3 按键自定义（物理按键）
副屏上通常有一颗触摸按键，你可以自定义它的动作：
- **单击**：默认“下翻页”
- **双击**：默认“上翻页”
- **长按**：默认“切换方向”
你可以在“设置 → 按键”中，为这三种操作分配不同的动作（包括“无”来禁用误触）。

### 4.4 多屏独立管理
如果你同时连接了多块副屏，程序会自动识别，并在顶部工具栏显示下拉菜单（“屏幕1”、“屏幕2”）。
- **独立配置**：每一块屏幕都有自己的配置文件（保存在 `config/MSU2_MINI_<序列号>.json`）。
- **独立操作**：切换屏幕后，修改的页面、方向、颜色等设置只对当前屏幕生效，互不干扰。

## 第五部分：高级功能——完全自定义显示（MiniMark 模板引擎）

这是为懂一点编程（或者愿意复制粘贴）的用户准备的“彩蛋”功能。你可以像写代码一样，精确控制屏幕上每个像素画什么。

### 5.1 它是什么？
MiniMark 是一种简单的脚本语言，每一行执行一个绘制命令，从上到下执行。
你可以画文字、画矩形、画圆、插入图片，甚至显示动态数据（如 CPU 温度）。

### 5.2 快速上手例子
点击“主控”页的“自定义内容”按钮，在弹出的窗口中选择“显示多项数值”标签页，你会看到一个大的文本输入框。在里面输入：

```miniMark
c #ffffff          # 设置字体颜色为白色
f resource/Orbitron-Bold.ttf 16   # 设置字体和大小
m 10 10            # 移动到坐标 (10, 10)
p CPU:             # 绘制文字 "CPU:"
t 50 0             # 相对向右移动 50 像素
v 1                # 绘制第 1 项数据（CPU 占用）
```

点击“保存”或切换回主控，把小屏切到“自定义显示多项数值”页，你就能看到 CPU 占用率显示在屏幕上了。

### 5.3 常用命令速查表

| 命令 | 参数 | 说明 | 举例 |
| :--- | :--- | :--- | :--- |
| `p` | 文本 | 绘制文本 | `p Hello` |
| `c` | #RRGGBB | 设置颜色 | `c #ff8800` |
| `f` | 字体文件 字号 | 设置字体 | `f simhei.ttf 20` |
| `m` | X Y | 移动到绝对坐标 | `m 80 40` |
| `t` | DX DY | 相对当前位置移动 | `t 8 0` |
| `v` | 序号 [格式] | 绘制第 N 个传感器数值 | `v 1 {:.1f}%` |
| `i` | 图片路径 | 插入图片 | `i resource/logo.png` |
| `r` | X1 Y1 X2 Y2 | 画矩形 | `r 0 0 159 79` |
| `l` | X1 Y1 X2 Y2 | 画线条 | `l 0 40 159 40` |
| `o` | X Y 半径 | 画圆 | `o 80 40 20` |
| `g` | GIF路径 | 播放动图 | `g resource/anim.gif` |

### 5.4 图形化编辑器
如果你不想记命令，可以在“自定义内容”窗口切换到 **“图形化编辑”** 标签页。你可以通过“添加文本”、“添加数值”、“添加颜色”等按钮来可视化地构建显示布局，双击列表项即可编辑参数。这比直接写代码要直观得多！

## 第六部分：开发者专区——API 接口完全手册

这是本软件最强大的部分。通过 API，你可以将小屏集成到你自己的程序、网页或智能家居系统中。

### 6.1 开启 API 服务
1.  打开程序，进入 **“设置 → API接入”** 标签页。
2.  确保 **“启用 API 投屏服务器”** 处于勾选状态（默认开启）。
3.  默认端口为 **8632**，你可以修改它。如果设置了“访问令牌”，后续所有请求都需要带上它（通过 `X-API-Token` Header 或 `?token=` 参数）。
4.  点击“打开 API 文档”按钮，浏览器会打开一个投屏控制台和 API 说明。

### 6.2 核心概念
- **设备 (Device)**：默认为当前选中的屏幕。你可以通过参数 `device` 指定目标屏（如 `"屏幕1"`）。
- **帧 (Frame)**：小屏上显示的画面就是一张 `160x80` 的 RGB888 图像（所有投屏最终都会渲染成这种格式）。

### 6.3 常用 API 接口速查

所有请求均向 `http://127.0.0.1:8632` 发送。

**1. 基础信息**

- **GET /api/info**
    - 获取程序名称、版本、屏幕尺寸等信息。
    - 示例：`curl http://127.0.0.1:8632/api/info`

- **GET /api/pages**
    - 获取所有可用页面名称列表。
    - 示例：`curl http://127.0.0.1:8632/api/pages`

**2. 投屏控制（核心）**

- **POST /api/text** —— 投屏文字
    - Body (JSON)：`{"text": "你好小屏", "color": "#ff0000", "font_size": 20}`
    - 示例：`curl -X POST -H "Content-Type: application/json" -d '{"text":"Hello"}' http://127.0.0.1:8632/api/text`

- **POST /api/screen** —— 投屏图片
    - Body (JSON)：支持 `image`（Base64 编码的完整图片）、`rgb888`（原始像素数据）。
    - 示例（Python）：见下文 6.4 节。

- **POST /api/screen/raw** —— 最高效的投屏（推流）
    - Body：`application/octet-stream`，内容是 `160*80*3 = 38400` 字节的原始 RGB888 数据。
    - 适合从视频、摄像头或游戏画面中实时截帧推送。

- **POST /api/clear**
    - 清空投屏内容，回到 “API投屏” 页面。

**3. 页面控制**

- **POST /api/page** —— 切换页面
    - Body：`{"page": "时间"}` 或 `{"page": 1}`（使用页面 ID）。
- **POST /api/page/next** 和 **POST /api/page/prev**
    - 翻到下一张/上一张页面。

**4. 其他便利功能**

- **POST /api/stop**：停止当前投屏，恢复到 API 投屏页面。
- **POST /api/notify**：在程序的状态栏显示一条通知文本（不投屏）。`{"text": "任务完成！"}`。
- **POST /api/orientation**：修改屏幕方向。`{"direction": "next"}` 或 `{"direction": 2}`。
- **POST /api/screen/id**：触发“屏幕序号检测”功能，所有已连接屏幕显示自己的屏号（如“屏幕1”），数秒后自动恢复。

### 6.4 编程示例（Python）

下面这段 Python 代码演示了如何通过 `requests` 库投屏一张图片到小屏。

```python
import requests
import base64

# 1. 读取你要显示的图片（建议尺寸 160x80）
with open("my_pic.png", "rb") as f:
    img_data = f.read()

# 2. 将图片编码为 Base64
b64_data = base64.b64encode(img_data).decode()

# 3. 发送请求
url = "http://127.0.0.1:8632/api/screen"
payload = {
    "image": b64_data,
    "fit": "contain"  # 显示方式: contain/stretch/cover
}

response = requests.post(url, json=payload)
print(response.json())  # 打印返回结果
```

### 6.5 WebSocket 实时推流（高级）
对于需要高频更新（如游戏画面、摄像头）的场景，建议使用 WebSocket。
- **地址**：`ws://127.0.0.1:8632/ws`
- **二进制帧**：直接发送 `38400` 字节的 RGB888 原始数据，是性能最高的方式。
- **文本帧**：发送 JSON 命令（如 `{"type": "text", "text": "hello"}`），功能与 HTTP 接口一致。

## 第七部分：故障排除与常见问题 (FAQ)

### 7.1 程序打不开 / 闪退
- **原因**：可能是缺少 VC++ 运行库或系统环境问题。
- **解决**：
    1.  下载并安装 [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
    2.  如果闪退，查看程序目录下是否生成了 `crash_log.txt`，里面记录了错误详情，可以提交到 GitHub Issues。

### 7.2 连接不上屏幕 / 一直显示“设备未连接”
- **检查**：
    1.  设备管理器中是否有 **“未知设备”** 或有感叹号的 **“COM”** 端口？如果有，请安装 CH340/CH343 驱动。
    2.  换一根 USB 数据线（很多廉价线只有充电功能，没有数据传输功能）。
    3.  尝试重启程序或电脑。

### 7.3 屏幕画面是倾斜的 / 撕裂的
- **原因**：通常是串口通信繁忙或命令发送失败造成的。多发生在刚启动或快速切换页面时。
- **解决**：这是程序内置的容错机制会处理的。如果出现，可以：
    1.  点击一下“上翻/下翻”按钮，切换一次页面，通常能恢复。
    2.  在“设置 → 通用”中关闭再开启“防烧屏”，有时也能重置画面。
    3.  如果频繁出现，可以在“设置 → 通用”中降低“最大 FPS”（例如从 5 降到 2），减轻串口负担。

### 7.4 传感器数据（温度/风扇）显示 `--` 或不显示
- **原因**：
    1.  没有以管理员身份运行程序。部分硬件监控数据（尤其是 CPU 温度）需要管理员权限。
    2.  LibreHardwareMonitor 服务未启动或读取失败。
- **解决**：
    1.  右键点击 `MSU2_MINI_V2.exe`，选择 **“以管理员身份运行”**。
    2.  在“设置 → 监控显示 → 硬件详情”中，尝试使用“自由选择传感器”功能，手动勾选要显示的传感器。

### 7.5 API 接口返回 `invalid token`
- **原因**：你在“设置 → API接入”中设置了“访问令牌”，但请求时未携带。
- **解决**：在 API 请求的 Header 中加入 `X-API-Token: 你的令牌`，或在 URL 后加参数 `?token=你的令牌`。
