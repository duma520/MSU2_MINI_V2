## 第一部分：零基础入门篇（写给所有人）

### 1.1 什么是“USB副屏工具”？

简单来说，这是一个**能将您闲置的、带有USB接口的小屏幕（如USB迷你显示器、DIY的LCD小屏等）变成电脑的“智能信息中心”** 的软件。

想象一下，您的主显示器上工作繁忙，而这个小屏幕上可以实时显示：
- **时间与天气**：一个始终可见的精致时钟和今日天气。
- **电脑性能**：CPU、内存、网络速度的使用情况，如同给电脑戴上了“智能手表”。
- **系统监控**：磁盘读写速度、最耗资源的进程列表。
- **自定义信息**：您关心的任何数据，比如股票行情、待办事项、甚至是您自己的个性签名。

它的核心就是：**把PC上的数据，实时、漂亮地呈现在一块小巧的第二屏幕上。**

### 1.2 我需要准备什么？

1.  **硬件**：一块兼容的USB小屏幕（通常是基于WCH芯片的，如MSU2_MINI系列）。它通过USB数据线连接到您的电脑。
2.  **软件**：本程序 `MSU2_MINI_V2.py`（或打包后的`.exe`可执行文件）。
3.  **操作系统**：Windows（最佳支持）或Linux（需图形界面环境）。

### 1.3 第一次运行与基础设置

1.  **启动程序**：双击运行 `MSU2_MINI_V2.exe`（或通过Python运行脚本）。
2.  **连接设备**：将您的USB副屏插入电脑。软件通常会自动识别并连接。如果未连接，请在主界面点击“刷新”或“连接”按钮。
3.  **认识主界面**：
    -   **顶部标签**：分为 **“中控”** （进行所有核心操作）、“**电视墙**”（如果您有多个屏幕，可在此总览所有屏幕）和“**关于**”。
    -   **“中控” - “屏幕标签”**：如果您连接了多个副屏，这里会为每个屏幕创建一个独立的标签页（屏幕1、屏幕2...）。
    -   **屏幕子标签**：每个屏幕下又有三个子页面：
        -   **“主控”**：核心控制区。您在这里选择显示什么内容（页面）、调整方向、设置颜色等。
        -   **“设置”**：对当前屏幕进行深度个性化配置。
        -   **“设备信息”**：查看该屏幕的硬件和固件详情。

## 第二部分：基础应用篇（给每位用户）

这部分将教您如何让副屏“动起来”，展示您想要的内容。所有操作都在 **“中控”** 标签下的某一块屏幕的 **“主控”** 子页面中完成。

### 2.1 切换页面（让屏幕显示不同内容）

这是最基础的操作。在“主控”页面中，找到 **“页面”** 下拉框。您可以选择预置的丰富页面：

-   **时间**：全屏显示当前时间（大字，非常酷）。
-   **屏幕镜像**：将您电脑主屏幕或某个特定窗口的内容，实时投射到小屏上。
-   **动图(GIF)**：播放您预设在程序目录下的GIF动图。
-   **系统监控**：显示CPU、内存、磁盘、电池的综合使用率。
-   **网络流量**：实时显示上传和下载速度，并以柱状图展示趋势。
-   **文字跑马灯**：让自定义文本在屏幕上滚动显示，适合展示口号或通知。
-   **硬件详情**：显示CPU/GPU温度、风扇转速等传感器数据（需管理员权限）。
-   ...以及更多（天气、行情、番茄钟、纪念日等）。

**操作示例**：选择 **“时间”**，您的副屏会立刻变成一个漂亮的桌面时钟。

### 2.2 调整显示方向

如果您的屏幕放置方向是横屏或竖屏，可以在 **“方向”** 下拉框中调整，有正向、反向、90°/270°旋转等选项，直到图像显示正常。

### 2.3 修改文字颜色

在“主控”页面右侧，您会看到 **“文字颜色”** 区域：
1.  可以直接拖动 **R（红）、G（绿）、B（蓝）** 滑块来混合出您想要的颜色。
2.  也可以从下方的 **“配色方案”** 下拉框中，选择一套预设的优雅配色（如马卡龙、赛博朋克、中国传统色），颜色会立即生效。

## 第三部分：进阶定制篇（给追求个性的你）

### 3.1 完全自定义显示内容（MiniMark模板）

这是本工具最强大的功能之一，允许您像“拼积木”一样设计显示界面，而不需要写代码。

1.  在“主控”页面，点击 **“自定义内容”** 按钮。
2.  在弹出的窗口中，您可以看到两个主要标签页：
    -   **“显示多项数值”**：您可以自由选择要显示的6个硬件传感器（如CPU温度、风扇转速等），并为其命名。
    -   **“图形化编辑”**：这是设计的核心。您可以通过点击“添加命令”，用“积木”来搭建界面。
3.  **“图形化编辑”积木命令示例**：
    -   **`文本 (p)`**：显示一段文字。
    -   **`颜色 (c)`**：设置后续命令的颜色。
    -   **`数值 (v)`**：显示您在“显示多项数值”中选定的某个传感器的数值。
    -   **`矩形 (r)`** / **`线条 (l)`** / **`圆 (o)`**：绘制简单图形，制作仪表盘或进度条。
    -   **`位置 (m)`**：移动“画笔”到指定坐标 (`x, y`)。

**实战举例：制作一个极简的CPU监控器**

1.  在“显示多项数值”中，将第1项命名为“CPU”，项目选择为CPU负载传感器。
2.  切换到“图形化编辑”，点击“添加命令” -> “文本”，文字填“CPU:”。
3.  点击“添加命令” -> “位置”，X填`40`，Y填`0`。
4.  点击“添加命令” -> “数值”，数值项选择“1”，格式填`{:.0f}%`（表示显示为整数百分比）。
5.  点击“保存”或关闭窗口，返回主控页，选择“自定义显示多项数值”页面即可看到效果。

### 3.2 配置个性化页面

在屏幕的 **“设置”** -> **“页面内容”** 标签中，您可以深度配置每个页面的具体参数，例如：
-   **文字跑马灯**：修改滚动文本、速度、字号、背景色。
-   **天气/行情**：输入您的城市（支持中文，如“北京”）和想要监控的加密货币交易对（如`BTCUSDT`）。
-   **热搜**：调整显示条数、刷新间隔、是否自动滚动。
-   **世界时钟**：自定义您关注的时区，格式为 `名称|偏移`，例如 `东京|9`。

### 3.3 管理你的配色方案

在 **“设置” -> “配色方案”** 中，您可以：
-   浏览所有内置的260+套专业配色（从莫兰迪到霓虹风应有尽有）。
-   **混合搭配**：在“监控显示”等设置区，您可以让“文字颜色”来自“马卡龙”方案，而“柱状图颜色”来自“赛博朋克”方案。
-   **存为新方案**：当您调出满意的颜色组合后，点击“存为新方案”，即可保存并随时调用。

## 第四部分：专业应用篇（给高级用户与开发者）

### 4.1 多屏幕独立控制

如果您连接了多个USB副屏，它们会以独立的标签页呈现在“中控”中。**每个屏幕都有自己的独立配置**：
-   屏幕1可以显示时间，屏幕2可以显示网络流量。
-   每个屏幕的颜色、方向、页面设置都互不干扰，真正做到“一屏一用”。

### 4.2 强制投屏

在 **“设置” -> “API接入”** 中，勾选 **“强制投屏”**。开启后，无论当前屏幕处于哪个页面（比如正在显示时间），外部程序都能通过API“强制”投送内容上去。当投屏停止后，屏幕会自动恢复到原先的页面（如时间）。这对于需要临时打断显示内容的场景非常有用。

### 4.3 屏幕序号检测（实用排障功能）

如果您有多个副屏，想快速知道哪个是“屏幕1”，哪个是“屏幕2”？
在 **“设置” -> “API接入”** 中点击 **“检测屏幕”** 按钮，或者通过API发送 `screen_id` 命令。所有已连接的副屏会同时显示自己的序号（屏幕1、屏幕2...），几秒后自动恢复原画面。

### 4.4 接入协议与API使用指南（开发者必读）

本工具为开发者提供了极其丰富的本地接入方式，让您能将任何数据（如股票指标、游戏状态、业务监控）推送到副屏。

#### 4.4.1 核心概念
-   **服务地址**：默认 `http://127.0.0.1:8632`。
-   **目标屏**：所有API请求都可选 `"device": "屏幕1"` 参数来指定投送到哪个屏幕。
-   **数据格式**：绝大多数命令采用 `JSON` 格式，包含一个 `"type"` 字段来指定命令类型。

#### 4.4.2 统一命令执行器
所有接入协议（HTTP, WebSocket, TCP等）都支持一套统一的命令格式，您只需发送一个JSON即可。

**基础命令示例**：

```json
// 投屏文本
{"type": "text", "text": "Hello World!", "font_size": 24, "color": "#00ff00"}
// 投屏图片 (Base64)
{"type": "screen", "image": "/9j/4AAQSkZJRg...", "fit": "contain"}
// 清屏
{"type": "clear"}
// 切换页面
{"type": "page", "page": "时间"}
```

#### 4.4.3 主要接入方式及举例

1.  **HTTP REST API（最通用）**
    -   **投屏一张PNG图片**:
        ```bash
        # 假设图片已转为Base64编码
        curl -X POST http://127.0.0.1:8632/api/screen -H "Content-Type: application/json" -d '{"image":"iVBORw0KGgo..."}'
        ```
    -   **获取当前副屏截图**:
        ```bash
        curl http://127.0.0.1:8632/api/screenshot
        ```

2.  **WebSocket（实时推流）**
    -   适用于高频数据更新，如每秒30帧的视频流。
    -   连接 `ws://127.0.0.1:8632/ws`。
    -   发送**二进制帧**：直接发送 `160*80*3` 字节的原始RGB888数据，这是效率最高的投屏方式。
    -   发送**文本帧**：发送与HTTP请求体相同的JSON命令。

3.  **TCP Socket（简单高效）**
    -   连接到 `127.0.0.1:8633`（端口号=API端口+1）。
    -   每条命令为一行JSON，以换行符 `\n` 结束，服务器会回复一行JSON响应。

    **Python示例**:
    ```python
    import socket
    import json

    sock = socket.create_connection(("127.0.0.1", 8633))
    cmd = json.dumps({"type": "text", "text": "来自TCP的问候"}) + "\n"
    sock.sendall(cmd.encode())
    response = sock.recv(1024)
    print(response)
    sock.close()
    ```

4.  **UDP（简单广播）**
    -   发送到 `127.0.0.1:8634`，每条数据报为一个JSON命令。

5.  **热文件夹（零编程投屏）**
    -   将图片或 `txt` 文件拖入程序目录下的 `hotfolder/` 文件夹。
    -   图片会被自动缩放并投屏到副屏，`txt` 文件的内容会被作为文本投屏。文件名可以指定目标屏，例如 `屏幕1_my.jpg`。

6.  **其他协议**
    -   **ZeroMQ**：端口 `8635` (REP/REQ模式)。
    -   **Windows命名管道**：`\\.\pipe\MSU2_MINI_V2_api`。
    -   **stdin管道**：通过 `echo '{"type":"page","page":"时间"}' | python MSU2_MINI_V2.py` 这样的方式控制。

#### 4.4.4 关键API端点速览

| 类型 | 方法 | 端点 | 说明 |
| :--- | :--- | :--- | :--- |
| **信息** | GET | `/api/health` | 健康检查 |
| **信息** | GET | `/api/status` | 获取所有屏幕综合状态 |
| **信息** | GET | `/api/screenshot` | 获取某屏当前画面（PNG） |
| **控制** | POST | `/api/page` | 切换页面，如 `{"page": "时间"}` |
| **控制** | POST | `/api/page/next` | 翻到下一页 |
| **控制** | POST | `/api/device/select` | 切换当前操作的屏幕 |
| **投屏** | POST | `/api/screen` | 投屏一整张图像 |
| **投屏** | POST | `/api/text` | 投屏文本 |
| **投屏** | POST | `/api/clear` | 清屏 |
| **投屏** | POST | `/api/marquee` | 设置并切换到跑马灯页 |
| **配置** | GET | `/api/config` | 读取当前屏幕完整配置 |
| **配置** | POST | `/api/config/set` | 修改配置，如 `{"marquee_text": "新内容"}` |

更完整的接口定义和参数说明，请访问 `http://127.0.0.1:8632/api/openapi.json` 查看OpenAPI规范，或在浏览器中打开 `http://127.0.0.1:8632` 使用网页控制台。

## 第五部分：疑难解答与技巧

-   **屏幕无反应/未连接**：
    1.  检查USB线是否连接好。
    2.  在软件“中控”页点击“刷新”按钮。
    3.  确认无其他串口软件（如Arduino IDE）占用该端口。
    4.  在“设备信息”页查看是否有USB描述符，若无则可能是驱动问题。

-   **画面倾斜/错位**：
    这通常是命令流被意外中断导致的。软件已内置自动恢复机制（强制重置LCD方向），如果频繁出现，可以尝试降低“最大FPS”值，或检查USB线缆质量。

-   **传感器数据为“--”**：
    -   硬件详情、温度等数据需要**以管理员身份运行**程序。
    -   在“硬件详情”设置中，手动勾选您想监控的传感器类型（如`Temperature`、`Fan`）。

-   **更改设置后未生效**：
    大部分设置在更改后会立即生效。如果未生效，可以手动在“主控”页点击一下“方向”下拉框（切换一下再切回来），触发屏幕刷新。
