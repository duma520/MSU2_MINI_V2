## 🚀 从零基础到高级应用完全指南

这份指南将带你从“这是什么”到“我能用它做什么”，再到“我能让它做什么”。

### 第一部分：认识你的新伙伴——这是什么？

*   **一句话概括**: 这是一个运行在电脑上的强大软件，它能把一个USB接口的小屏幕（通常用于DIY项目）变成你的电脑扩展信息中心。
*   **它像什么？** 想象一下电脑机箱上的一个小屏幕，或者一个桌面摆件。它可以显示：
    *   **实用信息**: 时间、天气、股票行情、电脑CPU/内存/网络占用率。
    *   **酷炫特效**: 动态GIF图、系统监控仪表盘、文字跑马灯。
    *   **生产力工具**: 番茄钟、待办事项、纪念日倒计时、世界时钟。
    *   **娱乐功能**: 播放音乐、显示热搜榜。
    *   **镜像功能**: 实时显示你电脑屏幕的某个区域（比如游戏小地图），甚至带有放大镜效果。

### 第二部分：快速上手指南（零基础必读）

别担心，跟着下面几步，你很快就能让它亮起来。

**1. 准备工作 (硬件和软件)**

*   **硬件**: 一个USB接口的SPI串口屏幕（如市面上常见的MSU2_MINI或其兼容型号）。
*   **软件**:
    1.  从GitHub页面下载最新版本的 `MSU2_MINI_V2.exe` (或源代码)。
    2.  确保你的电脑已安装好USB串口驱动（通常购买屏幕时会提供，或使用CH340/CP210x等通用驱动）。

**2. 连接设备**

1.  用USB线将小屏幕连接到电脑。
2.  如果屏幕没有自动亮起，不用担心，软件会控制它。
3.  打开设备管理器，在“端口 (COM和LPT)”下，你应该能看到一个新的COM端口，比如 `COM15`。记住这个端口号。

**3. 启动软件并建立连接**

1.  双击运行 `MSU2_MINI_V2.exe`。
2.  软件主界面左上角会显示“设备未连接”。
3.  软件会自动扫描并连接你的屏幕。如果一切顺利，几秒钟后，左上角会变成绿色的“设备已连接”。
4.  **如果无法连接**:
    *   检查USB线是否插好。
    *   可以尝试在软件的命令行或设置中指定端口。例如，创建一个快捷方式，在目标后面加上 `--com COM15`。
    *   如果还是不行，请查看后面的“故障排除”部分。

**4. 体验第一个画面——屏幕镜像**

这是最直观的功能，能让你立刻看到效果。

1.  在软件主界面的 **“屏幕镜像窗口”** 下拉框中，选择你当前正在使用的窗口，比如“桌面”或“浏览器”。
2.  此时，你的小屏幕应该会实时显示你选中的窗口内容！（如果画面是黑的，尝试选择其他窗口或使用“桌面”）。
3.  你可以在设置中调整 **“最大FPS”** (帧率) 来让画面更流畅或降低CPU占用。

**至此，你已经成功让副屏工作起来了！** 接下来，我们深入探索它的强大功能。

### 第三部分：核心功能详解

软件的功能非常多，但组织得很清晰。我们将按“主控”和“设置”两大模块来介绍。

#### 一、主控界面 (控制中心)

这是你日常使用最频繁的面板。

*   **1. 设备选择与状态**
    *   **已连接设备**: 如果你连接了多个屏幕，可以在这里切换，每个屏幕的设置和显示内容都是独立的。
    *   **设备状态灯**: 红色为未连接，绿色为已连接。

*   **2. 显示控制**
    *   **页面切换**: 你可以通过点击 **“▲上翻”/“▼下翻”** 按钮，或直接从 **“页面下拉列表”** 中选择，来切换小屏幕显示的内容。
    *   **显示方向**: 通过下拉列表，你可以将屏幕内容旋转0°、90°、180°，适应不同的安装方向。

*   **3. 内容烧写 (写入屏幕硬件)**
    这部分是将图片、动图等数据永久写入屏幕的Flash存储器中。
    *   **闪存固件**: 写入屏幕的底层固件文件（一般是`.bin`格式）。
    *   **背景/相册/动图**: 分别对应“时间”页面的背景、“相册”页面的单张图片和“动图”页面的动画。支持常见的图片格式（JPG, PNG, GIF等）。
    *   **提示**: “烧写”一次后，数据就存在屏幕里了，即使不连接电脑，屏幕（如果本身有固件支持）也能显示这些内容。

*   **4. 视觉微调**
    *   **文字颜色**: 你可以通过滑块或从丰富的预设色板中快速选择，来改变“时间”、“系统监控”等页面的文字颜色。
    *   **动图间隔**: 控制“动图”页面的播放速度。
    *   **屏幕分辨率**: 如果你的屏幕不是默认的160x80，可以在这里手动选择或点击“检测屏幕”自动识别。

*   **5. 自定义内容入口**
    *   点击 **“自定义内容”** 按钮，你将进入一个全新的世界——MiniMark编辑器。这是软件最灵活、最强大的部分，我们将在高级应用章节详细讲解。

*   **6. 实时预览**
    *   主界面下方会有一个实时预览窗口，让你无需低头看小屏幕，也能在电脑上看到小屏幕当前显示的内容（需在设置中开启“实时预览”）。

#### 二、设置界面 (深度配置)

点击“设置”标签页，你可以对软件进行全方位定制。设置页内部又分为多个子标签页，方便查找。

*   **通用**
    *   **防烧屏**: OLED屏幕长期显示静态画面容易“烧屏”。开启此功能后，画面会每隔30秒微移1个像素，有效延长屏幕寿命。
    *   **开启实时预览**: 在主界面显示小屏幕内容的预览。
    *   **开机自启动**: 让软件随Windows系统自动启动。
    *   **界面语言**: 支持中文和英文切换。

*   **自动化**
    *   **自动翻页轮播**: 让屏幕像幻灯片一样，每隔几秒自动切换到下一个页面。
    *   **无操作息屏超时**: 设定一个时间（秒），如果期间没有按键操作，屏幕将自动熄灭以省电。按一下屏幕上的物理按键即可唤醒。

*   **按键**
    *   如果你的USB副屏带有一个或多个物理按键，你可以自定义“单击”、“双击”、“长按”分别触发的动作（如下一页、上一页、切换方向）。

*   **页面内容** (每个页面独立设置在这里)
    *   **文字跑马灯**: 设置滚动的文字内容、字号、颜色和滚动速度。
    *   **天气与行情**: 输入城市名（支持中文如“北京”或英文“Beijing”）来获取天气；输入交易对（如 `BTCUSDT,ETHUSDT`）来查看加密货币行情。
    *   **热搜**: 设置显示的热搜条数、字体大小、翻页速度和是否自动刷新。
    *   **时间**: 设置番茄钟的时长，以及世界时钟的时区（如 `北京|8,伦敦|0`）。
    *   **纪念日/待办**: 直接在文本框中编辑你的纪念日（格式：`名称|MM-DD`）和待办事项列表。

*   **监控显示** (系统监控类页面设置)
    *   **进程**: 设置进程TOP页面显示的进程数量。
    *   **硬件详情**: 这是专业的系统监控设置。你可以选择显示哪些硬件传感器类型（温度、风扇、电压、负载、功耗），甚至**自由选择**来自LibreHardwareMonitor的**任意传感器**进行精确监控。
    *   **仪表盘**: 你可以像拼图一样，自定义仪表盘上显示哪些项目（CPU、内存、GPU温度、风扇转速等），并为每个项目单独设置颜色。甚至可以为每个仪表项目**单独指定**一个传感器，实现监控的绝对自由。

*   **屏幕镜像**
    *   **镜像局部放大（跟随鼠标）**: 开启后，小屏幕会显示鼠标周围区域的放大画面，非常适合在做精细演示或观看细节时使用。

*   **数据管理**
    *   **导出/导入配置**: 你可以将自己精心调校好的一套配置（包括所有页面设置、颜色、自定义模板等）导出为`.json`文件，分享给朋友或在不同电脑间迁移。
    *   **检查更新**: 一键检查GitHub上是否有新版本发布。

### 第四部分：高级应用——自定义显示 (MiniMark 引擎)

这是本软件的灵魂所在，它让你从“选择页面”转变为“创造页面”。

#### 什么是 MiniMark？

它是一种简单的**标记语言**，类似于HTML。你通过在文本框中编写一些简单的“命令”，就能在屏幕上画文字、图形、图片，甚至是动态数据。

**为什么说它强大？**
*   **个性化**: 你可以设计出完全属于自己的监控面板、信息看板。
*   **数据驱动**: 能够实时显示电脑上的各种数据（CPU、内存、网络、自定义传感器的数值）。
*   **图形化编辑器**: 即使不懂编程，你也可以通过“图形化编辑”标签页，像搭积木一样拖拽添加元素，完全无需接触代码。

#### 从示例开始

*   **示例1: “科技感”监控面板**
    ```miniMark
    i resource/example_background.png   # 首先绘制一个背景图
    c #ff3333                           # 设置颜色为红色
    f resource/Orbitron-Regular.ttf 22  # 设置字体
    m 16 16                             # 移动到坐标(16,16)
    v 1 {:.0f}                          # 绘制数据项1 (比如CPU占用)
    p %                                 # 绘制百分号
    m 96 16
    v 2 {:.0f}
    p %
    m 96 44
    v 3 {:.0f}
    p %
    ```
    **效果**: 在背景图上，用科技感字体显示了三个数值（对应你设置的自定义数据项1、2、3）。

*   **示例2: “简单”文本列表**
    ```miniMark
    m 8 8
    f resource/Orbitron-Bold.ttf 20
    p CPU
    t 8 0
    c #3366cc
    v 1
    m 8 28
    c #000000
    f resource/Orbitron-Bold.ttf 20
    p GPU
    t 8 0
    c #3366cc
    v 2
    ```
    **效果**: 清晰列出“CPU”和“GPU”的标签与实时数值。

#### MiniMark 命令速查表 (面向专业用户)

| 命令 | 参数 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `p` | `[文本]` | 绘制文本，并自动移动光标到文本末尾。 | `p Hello World!` |
| `a` | `[锚点]` | 设置文本锚点，控制文字对齐方式。 | `a la` (左对齐) / `a ra` (右对齐) / `a ct` (居中) |
| `m` | `[x] [y]` | 将光标**移动**到指定的绝对坐标。 | `m 10 20` |
| `t` | `[dx] [dy]` | 将光标**相对当前位置**移动。 | `t 50 0` (向右移50像素) |
| `f` | `[字体文件] [字号]` | 更换当前字体。 | `f ./simhei.ttf 16` |
| `c` | `[Hex颜色]` | 更换当前绘图颜色。 | `c #FF0000` (红色) |
| `i` | `[图片文件]` | 在光标位置绘制一张图片。 | `i resource/logo.png` |
| `v` | `[数据项序号] [格式]` | 绘制“自定义数据项”的数值，序号对应“设置→自定义”中的第1~6项。 | `v 1 {:.1f}` (显示数据1，保留1位小数) |
| `r` | `[x1] [y1] [x2] [y2]` | 绘制一个矩形。 | `r 10 10 150 70` |
| `l` | `[x1] [y1] [x2] [y2]` | 绘制一条线段。 | `l 0 0 159 79` |
| `o` | `[x] [y] [半径]` | 绘制一个圆（或椭圆）。 | `o 80 40 20` |
| `g` | `[GIF文件]` | 在光标位置播放一个GIF动图。 | `g resource/anim.gif` |

#### 图形化编辑器 (你的得力助手)

为了让非程序员也能轻松使用，我们提供了图形化编辑器。

1.  点击主界面的 **“自定义内容”**。
2.  切换到 **“图形化编辑”** 标签页。
3.  你会看到一个类似“元素列表”的界面。
4.  **添加元素**: 点击“添加文本”、“添加数值”等按钮，会弹出一个友好的对话框让你填写内容。
5.  **编辑/删除/排序**: 双击列表项可以编辑，选中后可以使用“删除”、“上移”、“下移”按钮调整。
6.  **使用预设**: 点击“预设模板”，可以一键套用“大字时钟”、“监控面板”等现成模板。

### 第五部分：面向开发者与专业人士的技术说明

#### 1. 多设备与独立配置机制

*   **核心设计**: 每个物理设备通过其 **USB序列号 (Serial Number)** 作为唯一标识。
*   **配置文件**: 配置文件存储在 `./config/MSU2_MINI_<SN>.json`。如果序列号为空或冲突，则会回退到使用端口号 (`COMx`) 进行区分。这保证了即使你同时连接多个相同的设备，它们的设置也不会混乱。
*   **原子写入**: 为了防止配置文件在写入时因程序崩溃而损坏，系统采用“先写临时文件，再重命名替换”的策略，确保文件完整性。

#### 2. 渲染管道 (Render Pipeline)

为了保证流畅的画面和稳定的帧率，软件设计了一套高效的渲染管道：
1.  **截图/捕获线程**: 负责从窗口、桌面或摄像头抓取原始图像数据。
2.  **处理/编码线程**: 将原始图像缩放、裁剪到屏幕分辨率，并转换为屏幕所需的 `RGB565` 格式。此步骤包含防烧屏偏移计算。
3.  **发送线程**: 将编码后的数据通过串口发送给硬件设备。
4.  **流水线同步**: 使用 `queue.Queue` 进行线程间通信，并通过 `screen_frame_generation` 计数器丢弃过时的帧，防止画面撕裂或倾斜。

#### 3. 串口通信协议与稳定性保障

*   **分块写入**: 对于大块数据（如图像帧），单次 `write` 可能因超时而失败。软件将其分为1KB大小的块进行写入，并逐块校验，有效避免命令流截断。
*   **读写锁与看门狗**: 使用 `SER_lock` 保证串口操作的原子性。LCD方向看门狗会定期强制重置方向，防止因通信错误导致的状态不同步。
*   **按键避让**: 在串口忙于发送图像帧时（`serial_busy` 标志），按键扫描线程会主动避让，防止按键ADC读取命令插入到帧数据中，造成命令流交错和画面错乱。

### 第六部分：故障排除 (FAQ)

**Q1: 软件提示“设备未连接”，但屏幕明明插上了。**
*   **A1**: 检查以下几点：
    *   USB线是否完好，尝试换一个USB口。
    *   是否安装了正确的串口驱动？
    *   是否有其他软件（如Arduino IDE）占用了该COM口？关闭它们。
    *   尝试在快捷方式中指定端口：`MSU2_MINI_V2.exe --com COM15`。

**Q2: 小屏幕显示的画面是倾斜的/撕裂的。**
*   **A2**: 这通常是命令流截断或错位导致的。
    *   软件已内置了多重容错机制（看门狗、强制重置）。通常等待几秒钟或切换一次页面即可自动恢复。
    *   如果频繁出现，请检查USB线是否接触不良，或尝试降低“最大FPS”。

**Q3: 自定义页面显示 `--` 或 `<*>`。**
*   **A3**: 这表明软件无法获取该数据项的值。
    *   **最常见原因**: 权限不足。部分硬件传感器（如CPU温度）需要**管理员权限**才能读取。请右键点击软件图标，选择“以管理员身份运行”。
    *   检查你在“自定义内容”中选择的传感器名称是否正确。

**Q4: 如何重置所有设置到默认状态？**
*   **A4**: 关闭软件，然后进入软件目录下的 `config` 文件夹，删除或移走所有的 `MSU2_MINI_*.json` 文件。重新启动软件将会创建全新的默认配置文件。

**Q5: 开机自启动设置后无效。**
*   **A5**: 请确保软件以管理员身份运行，因为写入注册表需要相应权限。
