整合 https://github.com/dimangopie/just-fun-for-MSU2_MINI 和 https://github.com/dchg43/msu2_mini 的程序。

## 欢迎使用 USB 副屏工具！

这是一款功能强大、高度可定制的电脑副屏软件。它能将任何带有USB接口的小屏幕（如常见的USB小显示屏、0.96寸OLED、1.54寸LCD等）变成你电脑的专属信息中心。

无论你是想：
-   **给电脑增加一个炫酷的硬件监控仪表盘**；
-   **在游戏时通过副屏看到系统状态，无需切换窗口**；
-   **用副屏显示时钟、日历、待办事项，提高工作效率**；
-   **或者只是一个喜欢折腾、追求个性化的极客**；

这个工具都能满足你。它集成了屏幕镜像、系统监控、自定义界面、多媒体播放控制等几十种功能，并且支持多屏独立配置，是所有USB副屏爱好者的终极利器。

## 第一章：零基础入门指南（5分钟上手）

如果你刚接触这个软件，别怕，按照下面的步骤，你很快就能让你的小屏幕亮起来。

### 1.1 准备工作

1.  **硬件连接**：将你的USB小屏幕通过USB数据线连接到电脑的USB接口。
2.  **驱动安装**：确保你的电脑已识别该设备。通常，Windows会自动安装驱动。如果设备未识别（在设备管理器中出现感叹号），你可能需要安装CH340或CP210x等USB转串口驱动。
3.  **软件下载**：
    -   前往项目的GitHub发布页面（[https://github.com/duma520/MSU2_MINI_V2/releases](https://github.com/duma520/MSU2_MINI_V2/releases)）下载最新版的 `MSU2_MINI_V2.exe` 文件。
    -   如果下载的是源代码，则需要安装Python环境并安装依赖库。我们推荐新手直接下载编译好的 `.exe` 文件，解压后双击即可运行。
4.  **运行软件**：双击 `MSU2_MINI_V2.exe`。如果系统提示“需要管理员权限”，请**务必以管理员身份运行**（右键点击 -> “以管理员身份运行”），否则将无法读取CPU温度、风扇转速等核心硬件信息。

### 1.2 连接你的第一块副屏

打开软件后，你会看到一个主窗口。

-   **自动连接**：主窗口左上角的“设备未连接”标签会变为绿色的“设备已连接”，表示软件已成功识别你的副屏。
-   **手动刷新**：如果未自动连接，点击设备栏的“刷新”按钮。
-   **问题排查**：
    -   **检查设备管理器**：在“端口 (COM和LPT)”下查看是否有未知设备或带有感叹号的设备。
    -   **更换USB接口**：尝试插入电脑的其他USB口。
    -   **管理员权限**：确保软件以管理员身份运行。

### 1.3 显示你的第一个画面

连接成功后，副屏上应该会显示出默认的画面（通常是屏幕镜像）。我们来换一个更酷的：

1.  在软件主控页（“主控”标签页），你会看到一个名为“页面”的下拉列表。
2.  点击它，选择“**仪表盘**”。
3.  你的副屏会立即切换，开始显示CPU、内存等硬件信息。

**恭喜你！** 你已经成功驱动了你的USB副屏。就这么简单！

### 1.4 简单设置

-   **切换页面**：你可以通过“主控”页的“▲上翻”和“▼下翻”按钮，或者在页面下拉列表中选择不同功能。常见的页面包括：
    -   **时间**：显示大号数字时钟。
    -   **屏幕镜像**：将电脑屏幕的一部分复制到副屏。
    -   **网络流量**：以曲线图显示网络上传下载速度。
-   **调整方向**：如果你的屏幕显示是倒着的，可以在“显示方向”下拉列表中选择“反向(180°)”进行修正。

现在，你已经掌握了软件最核心的操作！接下来，让我们看看它到底有多强大。

## 第三章：核心特色与高级玩法（通用功能）

这部分将深入讲解软件的一些核心机制和高级功能，这些功能是所有页面的基石。

### 3.1 多屏独立配置（核心功能）

**这是什么？**
如果你有多块USB副屏，这个功能允许你为每一块屏幕**保存独立的设置**。比如，屏幕A可以设置为“仪表盘”页面，显示红色主题；屏幕B可以设置为“网络流量”页面，显示蓝色主题。拔掉再插上，它们会自动恢复成各自的设置，互不干扰。

**如何实现？**
软件通过读取每个设备的**USB序列号(Serial Number)** 来区分它们，并为每个设备在`config/`目录下生成独立的配置文件（如 `MSU2_MINI_<序列号>.json`）。如果两个设备的序列号相同（极少数情况），则会通过COM端口号进一步区分。

### 3.2 配色方案系统（个性化核心）

**这是什么？**
这是软件的“皮肤系统”。它内置了超过260种专业的配色方案，从“马卡龙”到“赛博朋克”，从“中国传统色”到“莫兰迪”。你可以在“设置”->“配色方案”中浏览和管理它们。

**高级玩法：混合搭配**
不仅仅是整体套用，你还可以“混合搭配”：
1.  选择一个配色方案，它的颜色会出现在各个颜色设置项旁边的“色块下拉”菜单中。
2.  例如，你可以将“仪表盘”的CPU颜色从“马卡龙粉”中选取，而将内存颜色从“赛博朋克蓝”中选取。
3.  调整好后，点击**“存为新方案”**，你的这一套混搭组合就会被保存为一个新的自定义方案。

### 3.3 实时预览（所见即所得）

在主控页下方有一个“实时预览”窗口。它会模拟显示你的副屏当前显示的内容。当你调整文字大小、颜色、页面布局时，预览会同步更新，让你在电脑上就能看到修改效果，无需总是盯着小屏幕。

### 3.4 自动化与待机

-   **自动翻页轮播**：在“设置”->“自动化”中开启，软件会自动按设定的时间间隔循环切换页面。非常适合展示型场景（如店铺橱窗）。
-   **息屏待机**：在“设置”->“自动化”中设定“无操作息屏超时”。如果在设定时间内没有按下副屏的物理按键，小屏幕会自动熄灭。按一下按键即可唤醒，既能省电，又能防止OLED烧屏。

### 3.5 命令行动态控制

软件支持命令行参数，方便高级用户集成到脚本中。
-   `--page 页面名称`：启动时直接跳转到指定页面。例如：`MSU2_MINI_V2.exe --page 仪表盘`
-   `--com COMx`：启动时优先连接指定的COM端口。例如：`MSU2_MINI_V2.exe --com COM3`

### 3.6 其他实用功能

-   **隐藏到托盘**：点击“主控”页的“隐藏”按钮，软件会最小化到系统托盘，不占用任务栏空间。
-   **开机自启动**：在“设置”->“通用”中开启，软件会随电脑自动启动。
-   **配置导入/导出**：在“设置”->“数据管理”中，你可以保存当前的所有配置，或者在其他电脑上导入，实现一键迁移。
-   **防烧屏**：开启后，显示内容会每隔30秒微移1个像素，有效延长OLED屏幕的使用寿命。

## 第四章：自定义显示终极指南（MiniMark引擎）

`自定义显示（多项数值）`页面是整个软件的灵魂。它为高级用户提供了完全自由的创作空间。

### 4.1 什么是MiniMark引擎？

它是一个小型的**模板渲染引擎**。你可以通过编写一些简单的“命令”，来告诉屏幕在哪个位置画什么。它就像是一套用于160x80像素画布上的“编程语言”，但极其简单。

### 4.2 如何使用图形化编辑器（推荐）

对于不想记命令的普通用户，这是最友好的方式：

1.  在“主控”页点击“自定义内容”按钮，会弹出一个新窗口。
2.  切换到“**图形化编辑**”标签页。
3.  这里你会看到当前模板的**命令列表**。
4.  你可以通过下方的按钮来**添加**各种元素（如“添加文本”、“添加数值”、“添加矩形”等），软件会弹出对话框让你填写具体内容。
5.  列表可以自由**排序、编辑、删除**。
6.  右侧的**预览窗格**会实时显示你的设计效果。
7.  设计好后，点击“确定”，软件会自动生成对应的模板代码。

**示例**：用图形化编辑器创建一个“CPU使用率 85%”的显示。
-   操作：点击“添加文本” -> 输入“CPU:” -> 点击“添加数值” -> 选择“1”（对应第一个项目，你需要在“简单两项图表”或“显示多项数值”标签页中为项目1绑定CPU传感器）。
-   这样，你就完成了一个简单的监控项！

### 4.3 MiniMark 命令速查（专业参考）

如果你喜欢写代码，可以直接在“显示多项数值”标签页的文本框中编辑。以下是所有命令及其用途：

| 命令 | 语法 | 参数说明 | 示例 | 专业说明 |
| :--- | :--- | :--- | :--- | :--- |
| **`p`** | `p 文本` | 要绘制的文本内容。 | `p Hello World` | **文本绘制**。文本会使用当前颜色(`c`)和字体(`f`)绘制，并且绘制位置会根据锚点(`a`)自动移动。 |
| **`a`** | `a 锚点` | 锚点字符串，参考Pillow库。 | `a la` | **锚点定位**。`la`=左上角，`ra`=右上角，`ls`=左基线，`ct`=居中。控制文本的基准对齐点。 |
| **`m`** | `m x y` | 绝对坐标x, y。 | `m 10 20` | **移动到**。将当前绘图光标移动到画布上的绝对位置。 |
| **`t`** | `t dx dy` | 相对位移dx, dy。 | `t 8 0` | **相对移动**。相对于当前位置移动光标。常与`p`命令连用，实现文本的紧凑排列。 |
| **`f`** | `f 字体文件 字号` | 字体文件路径，字号。 | `f ./simhei.ttf 16` | **设置字体**。更换后续文本的字体样式和大小。 |
| **`c`** | `c 颜色值` | HTML十六进制颜色代码。 | `c #ff0000` | **设置颜色**。更改后续所有图形和文本的颜色。 |
| **`i`** | `i 图片路径` | 图片文件路径。 | `i ./logo.png` | **绘制图片**。在光标位置绘制一张图片。 |
| **`v`** | `v 序号 [格式]` | 数值序号（1-6），可选Python格式化字符串。 | `v 1` <br> `v 1 {:.1f}` | **绘制数值**。显示你在“显示多项数值”中选定的第`序号`个传感器的值。`{:.1f}`表示保留一位小数。 |
| **`r`** | `r x1 y1 x2 y2` | 矩形的左上和右下角坐标。 | `r 0 0 159 79` | **绘制矩形**。用当前颜色填充一个矩形区域。 |
| **`l`** | `l x1 y1 x2 y2` | 线条的起点和终点坐标。 | `l 0 0 159 79` | **绘制线条**。用当前颜色画一条直线。 |
| **`o`** | `o x y 半径` | 圆心坐标和半径。 | `o 80 40 20` | **绘制圆形**。用当前颜色画一个实心圆。 |
| **`g`** | `g 动图路径` | GIF动图文件路径。 | `g ./anim.gif` | **绘制动图**。在光标位置播放一个GIF动图（按时间自动选帧）。 |

### 4.4 专家级配置：传感器自由选择

在“仪表盘”和“硬件详情”的设置中，每个项目旁边都有一个“传感器”按钮。点击后，你可以**从系统中所有可用的硬件传感器列表中精确选择你想要的数据源**。这意味着：
-   如果你的电脑有多块显卡，你可以指定监控第二块GPU的温度。
-   如果默认的“CPU温度”不准，你可以手动选择一个软件认为正确的CPU核心温度传感器。
-   你可以监控主板上的电压、电流、甚至是水冷泵的转速。

**注**：绝大多数主板和硬件传感器信息需要**管理员权限**才能获取。

## 第五章：新手常见问题与故障排查

**Q1：软件打开后闪退或报错怎么办？**
**A1：**
1.  **检查管理员权限**：右键点击软件图标，选择“以管理员身份运行”。
2.  **查看日志**：在软件目录下会生成一个 `crash_log.txt` 文件，打开它，将里面的错误信息通过GitHub Issues提交给开发者。
3.  **文件完整性**：重新下载软件，确保所有文件（特别是`resource`文件夹和`device_protocol.json`）完整。

**Q2：副屏能连接上，但屏幕是黑的/白的，不显示任何内容？**
**A2：**
1.  **切换页面**：在软件上切换到其他页面，如“时间”，看是否有显示。如果有，说明原页面设置有问题。
2.  **检查分辨率**：在“主控”页的“屏幕分辨率”下拉框中，尝试选择你设备的正确分辨率（如128x64、240x240等）。
3.  **调整显示方向**：尝试切换不同的方向，有时因为初始方向不正确，画面可能显示在屏幕外。

**Q3：屏幕镜像画面是倾斜的、撕裂的，或者像栅栏一样？**
**A3：**
-   这是画面“倾斜”问题，通常由**命令流交错**引起。软件已内置多项防御机制（如分块写入、事务锁、清空队列等）。如果发生：
    1.  点击“主控”页的“上翻/下翻”按钮，强制刷新页面，软件会自动重置LCD方向。
    2.  如果频繁发生，尝试降低“最大FPS”，减少数据传输量。
    3.  确保没有其他串口软件（如Arduino IDE）同时占用了该COM端口。

**Q4：我修改了设置，但小屏幕没有立即变化？**
**A4：**
-   本软件的大部分设置都是**实时生效**的。如果没有变化，请检查你的修改是否是在当前连接设备的配置上进行的（特别是当你有多个副屏时）。在“已连接设备”下拉框中选择你要操作的屏幕，再进行修改。

**Q5：硬件监控（CPU温度、GPU负载等）显示“--”或“加载中…”？**
**A5：**
1.  **首要检查**：是否**以管理员身份运行**软件。
2.  **检查传感器列表**：在“自定义内容”或仪表盘的“传感器”选择对话框中，看是否能列出传感器。如果列表为空，说明LibreHardwareMonitor库未成功加载。
3.  **等待加载**：软件启动后会在后台加载硬件库，需要几秒钟时间，请稍候。

## 第七章：开发者与贡献者指南（专业开发信息）

### 7.1 技术栈

-   **语言**：Python 3
-   **UI框架**：Tkinter
-   **图像处理**：Pillow, OpenCV (cv2)
-   **系统监控**：psutil, LibreHardwareMonitor (通过 .NET 桥接)
-   **硬件通信**：pyserial, PyCameraList
-   **窗口管理**：win32gui, win32ui, ctypes (Windows Only)
-   **网络请求**：urllib

### 7.2 项目结构

-   `MSU2_MINI_V2.py`：**主程序文件**，包含了所有UI、逻辑和硬件通信代码。
-   `HardwareMonitor.py`：LibreHardwareMonitor的Python包装器，用于获取硬件传感器数据。
-   `resource/`：资源文件夹，存放字体、图标、示例图片等。
-   `config/`：用户配置文件存储目录。
-   `device_protocol.json`：设备协议配置文件，定义了不同设备的Flash布局等。

### 7.3 核心模块解析

1.  **`ScreenDevice` 类**：核心类，封装了单个副屏设备的所有状态、串口连接、配置、线程和渲染逻辑。
2.  **`MiniMark` 引擎**：负责解析自定义模板命令并渲染为图像。
3.  **多设备管理**：通过全局 `all_devices` 字典和 `_device_context` 线程本地存储，实现了对多块屏幕的并行管理。
4.  **渲染流水线**：对于屏幕镜像和视频流，采用了**生产者-消费者模式**，由 `screen_shot_task`（截图）和 `screen_process_task`（处理/压缩）两个线程组成，并通过队列通信，提高了效率。
5.  **配置管理**：每个 `ScreenDevice` 实例都拥有独立的 `config` 对象，实现了多屏配置隔离。配置以JSON格式保存，并采用**原子写入**（先写临时文件再替换）保证数据安全。

### 7.4 如何参与贡献

1.  **Fork项目**：从主仓库Fork一份代码到你的账户。
2.  **创建功能分支**：从 `main` 分支创建一个新的分支，如 `feature/my-new-feature`。
3.  **编写代码**：确保你的代码风格与项目保持一致，并添加适当的注释。
4.  **测试**：在至少一种设备上测试你的修改。

6.  **报告问题**：如果你发现了Bug或有功能建议，请在GitHub Issues中提交，并贴上相应的标签。
