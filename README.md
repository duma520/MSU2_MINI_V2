## 1. 前言：什么是USB副屏工具？

### 1.1 目标读者
无论你是：
*   **电脑小白**：想给桌面增加一个炫酷的“电子时钟”或“相册”。
*   **办公族**：希望实时监控电脑性能，或在副屏上固定显示重要日程/信息。
*   **游戏玩家**：希望在游戏时，小屏幕能显示GPU/CPU占用率和网速。
*   **主播/内容创作者**：需要一个可定制的信息面板来展示设备状态。
*   **硬件发烧友/DIY玩家**：拥有USB小屏幕（如MSU2 MINI），想深度开发所有潜能。
*   **开发者**：对项目源码感兴趣，想进行二次开发或学习。

本手册都为你提供了清晰的路径。

### 1.2 它能做什么？
这是一个为**USB小屏幕**设计的“超级大脑”和“万能工具箱”。它通过USB数据线与电脑相连，让小屏幕能够显示丰富多彩的内容，包括但不限于：

*   **动态内容**：GIF动图、相册幻灯片。
*   **实用工具**：全屏大字时钟、实时电脑性能监控（CPU/内存/磁盘/电池）、网络上传下载速度图表。
*   **画面投射**：将电脑屏幕的某个窗口或整个桌面镜像到小屏幕上，或显示USB摄像头的画面。
*   **终极自定义**：通过内置的 **“MiniMark”模板引擎**，你可以像写代码一样，自由组合文字、图片、数据，打造**独一无二**的信息显示界面。
*   **硬件保护**：内置“防烧屏”机制，有效延长OLED屏幕的使用寿命。

### 1.3 核心优势
*   **功能全面**：集成了市面上同类工具几乎所有功能，并在此基础上有创新。
*   **高度自定义**：从文字颜色、页面顺序到完全自定义的模板，自由度极高。
*   **性能优化**：专为USB通信优化，支持FPS调节，资源占用低。
*   **用户体验友好**：图形化界面清晰，支持托盘隐藏，一键切换。
*   **开源免费**：基于MIT协议，你可以自由使用、修改、分发。

## 2. 快速上手（5分钟从零开始）

### 2.1 准备工作
*   **硬件**：
    *   一台Windows电脑（本工具主要为Windows设计）。
    *   一个兼容的USB小屏幕（如MSU2 MINI，或其他基于相似芯片的方案）。
    *   USB数据线。
*   **软件**：
    *   下载本工具的最新发布版（.exe文件）或Python源码。
    *   （可选）如果你要使用“自定义硬件监控”，需要下载并运行 **[Libre Hardware Monitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)**。*注意：这不是必须的，基础系统监控可直接使用。*

### 2.2 软件安装与启动
1.  **绿色免安装**：本软件为绿色版，下载后解压到任意文件夹即可。
2.  **启动程序**：双击运行 `MSU2_MINI_V2.exe`。
    *   **管理员权限**：如果希望获取完整的硬件监控数据（如GPU温度、风扇转速等），建议右键点击程序，选择 **“以管理员身份运行”**。程序启动时也会有相应提示。

### 2.3 连接你的USB小屏幕
1.  使用USB线将小屏幕连接到电脑。
2.  观察屏幕是否亮起（通常显示默认LOGO或等待数据状态）。
3.  观察软件主界面左上方状态指示灯：
    *   **红色“设备未连接”**：请检查USB线是否插紧，或尝试更换USB端口。
    *   **绿色“设备已连接”**：恭喜你，连接成功！软件会自动识别设备。

### 2.4 切换第一个显示画面（屏幕镜像）
1.  在软件主界面找到 **“页面下拉列表”**。
2.  点击下拉框，选择 **“屏幕镜像”**。
3.  几秒钟后，你的USB小屏幕上应该会显示电脑桌面的内容！
4.  **进阶调整**：你可以在“屏幕镜像窗口”下拉框中选择“桌面”或任何其他打开的窗口（如浏览器、游戏、文件夹）。

### 2.5 隐藏到系统托盘
*   点击 **“隐藏”** 按钮，软件会最小化到Windows系统托盘（任务栏右下角）。
*   在托盘图标上右键，可以选择“显示”或“退出”。此功能方便你让副屏在后台持续运行。

## 3. UI界面与功能详解（保姆级指南）

### 3.1 主界面概览
软件主界面分为三个标签页（笔记本风格）：
1.  **主控**：进行所有核心操作，如烧写内容、切换页面、调整设置。
2.  **设置**：目前包含“防烧屏”开关。
3.  **关于**：查看版本信息、开源协议和更新日志。

### 3.2 “主控”面板：核心操作区

#### 3.2.1 设备状态栏
*   位于界面左上角，实时显示设备连接状态（红/绿灯）。
*   **提示**：右侧的“隐藏”按钮可以让你将程序最小化到托盘。

#### 3.2.2 四大烧写功能（向屏幕写入内容）
*这是什么？*  “烧写”指的是将图片、动图等数据**写入到小屏幕自身的Flash（闪存）芯片**中。这样即使断开电脑，某些模式（如动图）也能独立播放。

*   **① 选择/烧写 [闪存固件]**：
    *   **用途**：烧写非图片类的固件，例如字库、LOGO等（通常为.bin文件）。普通用户用得较少，多为开发或深度定制时使用。
    *   **操作**：点击“选择”选好.bin文件，点击“烧写”。
*   **② 选择/烧写 [背景图像]**：
    *   **用途**：为“时间”模式更换背景图片。
    *   **操作**：选择一张你喜欢的图片（如风景、LOGO），点击“烧写”后，在“时间”模式下就会显示该背景。
*   **③ 选择/烧写 [相册图像]**：
    *   **用途**：为“单个相册图片”模式准备一张图片。
    *   **操作**：选择图片并烧写，之后切换到“单个相册图片”模式即可显示。
*   **④ 选择/烧写 [动图文件]**：
    *   **用途**：播放GIF动图或一组序列帧图片。
    *   **操作1（GIF文件）**：直接选择一个 `.gif` 文件，软件会自动解析并烧录为36帧。
    *   **操作2（图片序列）**：准备36张图片，命名为 `A0.jpg`, `A1.jpg`... `A35.jpg`，选择其中第一张（A0.jpg），软件会自动识别并烧录。
    *   **提示**：烧写完成后，下方的“动图间隔”会自动给出建议值。

#### 3.2.3 页面控制与显示方向
*   **▲上翻 / ▼下翻**：在小屏幕的12种显示模式间快速切换（相当于物理按键）。
*   **页面下拉列表**：显示所有页面名称，可直接点击选择任意页面，是最直观的切换方式。
*   **显示方向下拉列表**：点击可选择屏幕旋转角度（0°, 180°, 水平镜像, 90°顺时针等），适应不同的屏幕摆放姿势。
*   **板载按键**：如果你的屏幕上有触摸或物理按键，默认为：**单击=下翻页，双击=上翻页，长按=切换显示方向**。

#### 3.2.4 文字颜色与预设色卡
*   **调色板**：通过R（红）、G（绿）、B（蓝）三个滑块调节，右侧预览框会实时显示颜色。
*   **预设色卡**：这是一个非常方便的功能！点击下拉框，里面有海量的预设颜色，分为：
    *   **基础色**：纯黑/白/红/绿/蓝等。
    *   **马卡龙色系**：柔和、小清新风格。
    *   **Material Design色系**：谷歌标准色彩，非常耐看。
    *   **暖/冷/暗/霓虹色系**：满足不同视觉主题。
*   此设置会影响“时间”、“系统监控”、“网络监控”以及自定义显示中的文字颜色。

#### 3.2.5 高级控制：FPS、窗口选择、相机选择、分辨率
*   **最大 FPS**：设定屏幕镜像或相机视频的刷新率。设置为“5”即每秒刷新5次。数值越高画面越流畅，但会占用更多USB带宽和CPU资源。对于静态画面，5-10 FPS足够；对于视频，可尝试15-20。
*   **屏幕镜像窗口**：选择要投射的画面源。
    *   **桌面**：整个电脑屏幕。
    *   **特定窗口**：如“Chrome浏览器”、“任务管理器”等。选择后，小屏幕只显示该窗口内容（即使是窗口被遮挡或部分移出屏幕，有时也能捕获，但部分游戏或全屏应用可能无效）。
*   **相机名称**：选择连接到电脑的USB摄像头。如果只有一个摄像头，通常选择默认项。
*   **屏幕分辨率**：这个非常关键！
    *   下拉菜单可手动选择常见分辨率（如160x80, 128x64, 240x240等）。
    *   **“检测屏幕”按钮**：软件会尝试从小屏幕的芯片中读取正确的分辨率并自动设置。**强烈建议连接设备后首先点击此按钮**，以确保显示比例正确，避免画面拉伸或错位。

### 3.3 “设置”面板

#### 3.3.1 防烧屏（OLED保护神）
*   **原理**：OLED屏幕长时间显示同一静态画面，容易导致像素老化（烧屏）。开启此功能后，软件会每隔**30秒**将画面内容在水平和垂直方向**微移1个像素**，人眼几乎无法察觉，但能有效防止像素点长期高亮，显著延长屏幕寿命。
*   **建议**：**强烈建议保持开启**。如果你的屏幕是LCD（液晶）屏，则无烧屏风险，可关闭。

### 3.4 “关于”面板
*   显示软件作者、版本、许可证、项目地址、构建日期。
*   列出了本项目所整合的两个上游开源项目（遵循MIT协议），体现了开源精神。
*   包含详细的**版本更新说明**，让你清楚了解每个版本的变化。

## 4. 显示模式详解（12种玩法全攻略）

### 4.1 动图模式
*   **适用人群**：所有人，尤其喜欢个性化桌搭的用户。
*   **功能**：循环播放烧录到屏幕里的动图（最多36帧）。
*   **设置**：通过“动图间隔”调整播放速度。数值越小，动画越快。
*   **应用场景**：显示卡通表情、动态Logo、简易动画天气预报等。

### 4.2 时间模式（大字时钟）
*   **适用人群**：办公族、学生。
*   **功能**：全屏显示超大数字的 **HH:MM** 时间，数字字体为32x64像素，清晰醒目。
*   **设置**：需要先烧写一张“背景图像”，否则背景为黑色。文字颜色通过“文字颜色”调整。
*   **应用场景**：电脑副屏时钟，摆在桌面看时间非常方便。

### 4.3 单个相册图片
*   **适用人群**：所有人。
*   **功能**：显示一张烧录进去的图片。

## 5. 高级功能：自定义显示内容（MiniMark模板引擎）

这是将你的小屏幕从“玩具”变成“生产力工具”的关键。

### 5.1 什么是“显示多项数值”？
你需要从 `Libre Hardware Monitor`（一个开源硬件监控软件，需要单独运行）中读取海量的传感器数据。本软件像一个“桥梁”，把`Libre Hardware Monitor`检测到的CPU温度、GPU频率、风扇转速、主板电压等成百上千个数据，通过**“下拉列表”** 的形式提供给你选择，然后用**“MiniMark模板代码”** 来决定怎么显示这些数据。

*   **第一步**：下载并运行 `Libre Hardware Monitor`（开启Web服务器功能，默认端口8085）。
*   **第二步**：在本软件的“自定义内容”窗口中，“显示多项数值”页签下，从下拉列表中选择你关心的项目（例如“CPU Core #1 - Temperature”、“GPU - Core Clock”等）。
*   **第三步**：在右侧的文本框中编写MiniMark代码，告诉屏幕“在什么位置、用什么字体、显示哪个项目的数据”。

### 5.2 什么是“显示两项图表”？
这是“多项数值”的简化版。它固定显示**两行**数据，每行左侧是你自定义的名称，右侧是数值，并且整个屏幕下半部分是一个实时更新的曲线图。如果你只需要监控两个数据（如上/下载速度、CPU/GPU温度），这个模式最简单、最直观。

### 5.3 MiniMark模板代码详解（从入门到精通）

MiniMark是一种非常简洁的脚本语言，每一行都是一个指令。

#### 5.3.1 基础指令速查表

| 指令 | 功能 | 示例 | 说明 |
| :--- | :--- | :--- | :--- |
| **`p [文本]`** | 绘制文本 | `p Hello World!` | 绘制文字，并自动移动到文字末尾。 |
| **`a [锚点]`** | 更改文本锚点 | `a la` | 锚点如 `la`（左对齐）、`ra`（右对齐）、`ma`（居中）。参考Pillow库的`anchor`参数。 |
| **`m [x] [y]`** | 移动到坐标 | `m 10 20` | 将绘制起点移动到 (10, 20) 像素处。 |
| **`t [x] [y]`** | 相对移动 | `t 80 0` | 在当前绘制起点上向右移动80像素。 |
| **`f [字体] [字号]`** | 更改字体 | `f simhei.ttf 16` | 改变后续文字的字体和大小。 |
| **`c #[HEX码]`** | 更改文字颜色 | `c #FF0000` | 改为红色。使用16进制色码。 |
| **`i [图片路径]`** | 绘制图片 | `i logo.png` | 在当前位置绘制图片。 |
| **`v [序号] [格式]`** | 绘制数据值 | `v 1 {:.1f}°C` | **最关键指令**。`序号`对应你前面选择的硬件项目序号（1,2,3...），`格式`是Python的字符串格式化语法。 |

#### 5.3.2 新手实例：制作一个简单的“CPU+内存”监视器

**需求**：在屏幕中央显示CPU占用率和内存占用率，带百分比符号。

**步骤**：
1.  在“显示多项数值”的下拉列表中，第1项选择“CPU - Total Load”，第2项选择“Memory - Load”。
2.  在模板框中输入以下代码：
    ```minimark
    # 代码解析：
    c #00FF00          # 1. 将颜色改为绿色
    f simhei.ttf 24    # 2. 使用24号黑体
    m 40 20            # 3. 移动到 (40, 20) 位置（约屏幕中央偏上）
    v 1 {:.0f}%        # 4. 绘制项目1（CPU），格式为“整数+%”
    m 40 50            # 5. 移动到下一行
    v 2 {:.0f}%        # 6. 绘制项目2（内存），同样格式
    ```
3.  点击“效果预览”查看，点击“确定”关闭窗口，然后在小屏幕上选择“自定义显示多项数值”页面。

#### 5.3.3 进阶实例：设计“科技感”性能面板

**需求**：显示CPU、GPU、内存三行数据，每行有名称和数值，对齐整齐，使用“Orbitron”科技字体。

**步骤**：
1.  在下拉列表中分别选择CPU、GPU、内存。
2.  输入代码：
    ```minimark
    # 使用科技字体，字号20，颜色为青色
    f resource/Orbitron-Bold.ttf 20
    c #00FFFF

    # 第一行: CPU
    m 8 8      # 从左上角开始
    p CPU      # 绘制"CPU"
    t 80 0     # 向右移动80像素，这是为了把数值和名称分开
    v 1        # 绘制项目1（CPU），不带格式

    # 第二行: GPU
    m 8 28     # 向下移动28像素
    p GPU
    t 80 0
    v 2

    # 第三行: RAM
    m 8 48
    p RAM
    t 80 0
    v 3
    ```
    **效果**：屏幕左侧显示整齐的“CPU”、“GPU”、“RAM”，右侧显示对应的数值，非常专业。

#### 5.3.4 专业实例：结合背景图、自定义字体、锚点布局

**需求**：使用背景图，文字右对齐，显示数值并带单位。

**步骤**：
```minimark
# 1. 先绘制背景图
i resource/example_background.png

# 2. 设置颜色和字体
c #FFA500          # 橙色
f arial.ttf 18     # 使用Arial字体

# 3. 使用锚点进行右对齐布局
a ra               # 锚点改为右对齐

# 4. 第一行：CPU温度，显示在右上角附近
m 150 15           # 移动到靠近屏幕右边缘处
v 1 {:.1f}°C       # 显示项目1并带一个°C符号

# 5. 第二行：GPU使用率，显示在右侧下方
m 150 45
v 2 {:.1f}%
```
**专业说明**：
*   **`a ra`**：设置了锚点为右对齐（`ra` = Right-Align），所有后续`p`和`v`指令绘制的文本都会以你指定的`m`坐标为右端点进行绘制，非常适合制作对齐的仪表盘。
*   **`{:.1f}`**：这是Python格式化语法，表示保留一位小数的浮点数。`°C`和`%`是直接写死的单位字符。
*   这个实例展示了如何将MiniMark从简单的“画文字”升级为“布局设计”。

## 6. 专业功能与性能调优

### 6.1 LCD分辨率自动检测与手动配置
*   **为什么需要？** 不同厂家、不同型号的小屏幕，物理分辨率可能不同（常见有160x80, 128x64, 240x240）。如果软件输出的分辨率与屏幕不匹配，画面会偏移、撕裂或无法满屏。
*   **最佳实践**：每次连接新屏幕后，先在“主控”面板找到“屏幕分辨率”，点击 **“检测屏幕”**。如果检测成功，会自动填充分辨率。如果失败（比如旧型号），请手动从下拉列表中选择。
*   **专业提示**：检测逻辑会读取设备内部的SFR（特殊功能寄存器）变量名，如`LCD_X`, `LCD_Y`等，并尝试解析其值。开发者可以查看控制台输出了解检测过程。

### 6.2 屏幕镜像与相机视频的“填充” vs “适应”
在屏幕镜像或相机视频模式下，有一个“填充/适应”选择，它们决定了源画面如何放入小屏幕。
*   **填充**：将源画面**拉伸或裁剪**，使其**完全覆盖**小屏幕。可能会导致画面被裁切，但无黑边。
*   **适应**：保持源画面的**长宽比**，将其**完整地**缩放至小屏幕内。画面全部可见，但可能会有黑边。
*   **选择建议**：若想看全内容（如代码、网页），用“适应”。若想画面更沉浸（如游戏画面），用“填充”。

### 6.3 防烧屏机制详解
*   **运动模式**：并非整个画面移动，而是采用预设的9个偏移量模式 `(0,0), (2,0), (0,1)...` 循环。每隔30秒切换一次。
*   **为什么选这些偏移量？** 这些偏移量组合能有效覆盖像素点，且运动幅度极小（最多2像素），几乎无感知，不会影响内容阅读。
*   **源码参考**：在 `update_burn_offset()` 函数中定义了完整的偏移量列表和切换逻辑。

### 6.4 后台运行与系统资源占用
*   **资源**：本软件经过优化，在空闲状态下CPU占用极低。屏幕镜像/视频模式下，可通过调低“最大FPS”来进一步降低资源消耗。
*   **守护进程**：软件拥有独立的 `daemon_task` 线程，负责持续扫描串口并管理设备连接，确保设备断开后能自动重连。
*   **流水线设计**：屏幕截图（`screen_shot_task`）和图片处理（`screen_process_task`）在两个独立的线程中通过`Queue`通信，避免了卡顿，提高了高帧率下的稳定性。

### 6.5 命令行参数（静默启动）
*   **功能**：在程序启动时附加参数，可以实现启动后自动最小化到托盘。
*   **用法**：
    *   创建快捷方式。
    *   在快捷方式的“目标”末尾添加 ` -hide`。
    *   示例：`"C:\YourPath\MSU2_MINI_V2.exe" -hide`
*   **适用场景**：设置开机自启时，不希望显示主窗口，直接后台运行。

## 7. 疑难解答与常见问题 (FAQ)

### 7.1 设备无法连接 / 显示“设备未连接”
*   **情况1：USB线没插好。** 换一个USB口，或换一根线测试。
*   **情况2：驱动未安装或冲突。** 部分USB转串口芯片需要驱动（如CH340）。请确保Windows已正确识别设备（可在设备管理器中查看）。
*   **情况3：端口被占用。** 关闭其他可能占用串口的软件（如Arduino IDE、其他串口调试工具）。
*   **情况4：设备进入休眠。** 拔掉USB线重新连接，或重启软件。

### 7.2 屏幕镜像显示黑屏/卡顿
*   **检查窗口**：确保你选择的“屏幕镜像窗口”是可见的（没有被完全最小化）。部分游戏（特别是全屏独占模式）无法被捕获。
*   **检查FPS**：尝试将“最大FPS”调低，比如从20降到10。
*   **检查缩放**：在高DPI缩放（如150%）的显示器上，捕获某些窗口可能会出现偏移或黑边，尝试选择“桌面”或调整屏幕缩放。
*   **管理员权限**：确保软件以管理员权限运行。

### 7.3 自定义内容显示 `<项目名>` 或数值不对
*   **原因1**：`Libre Hardware Monitor` 未正确运行或未开启Web服务器。请重新启动它。
*   **原因2**：权限不足。以管理员身份运行本软件和`Libre Hardware Monitor`。
*   **原因3**：在模板中使用的`v`指令的`序号`，与你在下拉列表中选择的项目**顺序不一致**。例如，下拉列表第1项是CPU，模板中 `v 1` 才能正确调用。
*   **原因4**：项目本身没有数据（如“风扇转速”在没有风扇的电脑上），会显示`<项目名>`。

### 7.4 动图播放速度不对或卡顿
*   **原因1**：播放速度受 **“动图间隔” + 通信延迟** 影响。软件内部会将“动图间隔”拆分为整数部分`second_times`和小数部分`photo_interval_var`，如果间隔设置过小（<0.02秒），可能受硬件通信速度限制无法达到，可适当调大。
*   **调试**：在烧写GIF时，软件会输出“建议动图间隔：XX秒”，按建议值设置可得到最优效果。

### 7.5 字体无法显示中文
*   **问题**：使用了类似`Orbitron`的西文字体，它不包含中文字符。
*   **解决方案**：在`f`指令中使用支持中文的字体，如**`simhei.ttf`（黑体）** 或 `msyh.ttf`（微软雅黑）。这些字体文件可以放在软件根目录或`resource`文件夹下，通过`f`指令指定。
